= Prerequisites for {aap-short} cluster automation

[role="_abstract"]
Before you run Automation templates on managed or hosted clusters, install the required operators and select the correct installation mode for the {aap-short} Resource Operator.

You must meet the following prerequisites to run Automation templates on your clusters:

* Install a supported version of {ocp-short}.
* Install the {aap-short} Resource Operator to connect Ansible jobs to the lifecycle of Git subscriptions. For best results when you use the Automation template to launch {aap-short} jobs, the {aap-short} job template must be idempotent when it is run. You can find the {aap-short} Resource Operator in the {ocp-catalog}.
* When you install the {aap-short} Resource Operator for managed cluster automation, select the `*-cluster-scoped` channel and select the _all namespaces_ installation mode.
