= Pushing custom labels from the ClusterCurator resource to the automation job pod

[role="_abstract"]
Use the `ClusterCurator` resource to push custom labels to the automation job pod that the Cluster Curator creates. You can push the custom labels on all curation types.

*Required access:* Cluster administrator

.Procedure

. Create or edit a `ClusterCurator` resource and add the labels that you want to push. See the following example:
+
[source,yaml]
----
apiVersion: cluster.open-cluster-management.io/v1beta1
kind: ClusterCurator
metadata:
  name: cluster1
  namespace: cluster1
  labels:
    test1: test1
    test2: test2
spec:
  desiredCuration: install
  install:
    jobMonitorTimeout: 5
    posthook:
      - extra_vars: {}
        name: Demo Job Template
        type: Job
    prehook:
      - extra_vars: {}
        name: Demo Job Template
        type: Job
    towerAuthSecret: toweraccess
----
