[#enable-gitops-appset]
= Enabling the _ApplicationSet_ resource in any namespace

[role="_abstract"]
You can enable the  `ApplicationSet` resources in any namespace on your hub clusters.

*Required access:* Cluster administrator

.Prerequsites

- Are there any prereqs?

.Procedure

. Enable the Argo CD `ApplicationSet` resource in any namespace on the hub cluster, complete the following steps: 

.. From your command-line interface, clone the GitHub repository by running the following command:

+
[source,bash]
----
git clone https://github.com/stolostron/multicloud-integrations
----

.. Go to the GitHub repository that you cloned by running the following command: 

+
[source,bash]
----
cd multicloud-integrations/deploy/appset-any-namespace
----

.. Enable the `ApplicationSet` resource in any namespace by running the following command: 

+
[source,bash]
----
 ./setup-appset-any-namespace.sh --namespace openshift-gitops --argocd-name openshift-gitops 
----

.. Verify that the {gitops-short} instance restarted and is running on your hub cluster. Run the following command on your hub cluster: 

+
[source,bash]
----
oc get pods -n openshift-gitops 
----

. Enable the `Application` resource in any namespace on the managed clusters. The {acm-short} {gitops-short} add-on launches a {gitops-short} instance that you can use to enable the `Application` resource in any namespace on your managed cluster. Complete the following steps:

.. On the hub cluster, create a global `ManagedClusterSetBinding` resource by adding the following YAML file sample: 

+
[source,yaml]
----
apiVersion: cluster.open-cluster-management.io/v1beta2
kind: ManagedClusterSetBinding
metadata:
  name: global
  namespace: openshift-gitops
spec:
  clusterSet: global
----

.. Apply the YAML file sample by running the following command: 

+
[source,bash]
----
oc apply -f managedclustersetbinding-example.yaml
----

.. On the hub cluster, create a `Placement` custom resource for selecting the managed clusters where the (gitops-short) add-on gets enabled. Add the following YAML file sample:

+
[source,yaml]
----
apiVersion: cluster.open-cluster-management.io/v1beta1
kind: Placement
metadata:
  name: all-openshift-clusters
  namespace: openshift-gitops
spec:
  tolerations:
  - key: cluster.open-cluster-management.io/unreachable
    operator: Exists
  - key: cluster.open-cluster-management.io/unavailable
    operator: Exists
  predicates:
  - requiredClusterSelector:
      labelSelector:
        matchExpressions:
        - key: vendor
          operator: "In"
          values:
          - OpenShift
----

.. Apply the YAML file sample by running the following command: 

+
[source,bash]
----
oc apply -f placement-example.yaml
----

.. On the hub cluster, create the `GitOpsCluster` resource and add the `gitopsAddon` specification. Your YAML file might resemble the following sample: 

+
[source,yaml]
----
apiVersion: apps.open-cluster-management.io/v1beta1
kind: GitOpsCluster
metadata:
  name: argo-acm-importer
  namespace: openshift-gitops
spec:
  argoServer:
    cluster: notused
    argoNamespace: openshift-gitops
  placementRef:
    kind: Placement
    apiVersion: cluster.open-cluster-management.io/v1beta1
    name: all-openshift-clusters
    namespace: openshift-gitops
  gitopsAddon:
    enabled: true
----

.. Apply the YAML file sample by running the following command: 

+
[source,bash]
----
oc apply -f gitopscluster-example.yaml
----

.. Verify that the {gitops-short} instance restarted and is running on your managed clusters by running the following command on your managed clusters: 

+
[source,bash]
----
oc get pods -n openshift-gitops 
----

.. On the hub cluster, modify the default policy template to enable the `Application` resource in any namespace on all managed clusters. The default policy template is created by the `GitOpsCluster` resource when the {gitops-short} add-on is enabled. Modify the policy by adding the following YAML file sample:

+
[source,yaml]
----
apiVersion: policy.open-cluster-management.io/v1
kind: Policy
metadata:
  annotations:
    policy.open-cluster-management.io/categories: PR.PT Protective Technology
    policy.open-cluster-management.io/controls: PR.PT-3 Least Functionality
    policy.open-cluster-management.io/standards: NIST-CSF
  name: argo-acm-importer-argocd-policy
  namespace: openshift-gitops
spec:
  disabled: false
  policy-templates:
  - objectDefinition:
      apiVersion: policy.open-cluster-management.io/v1
      kind: ConfigurationPolicy
      metadata:
        name: argo-acm-importer-argocd-config-policy
      spec:
        object-templates:
        - complianceType: musthave
          objectDefinition:
            apiVersion: argoproj.io/v1beta1
            kind: ArgoCD
            metadata:
              labels:
                apps.open-cluster-management.io/gitopsaddon: "true"
              name: acm-openshift-gitops
              namespace: openshift-gitops
----

.. Specify the `ARGOCD_APPLICATION_NAMESPACES` environment variable to `*` in the `acm-openshift-gitops` `ArgoCD` resource for the Argo CD application controller to reconcile applications in any namespace. View the following partial YAML file:

+
[source,yaml]
----
            spec:
              controller:
                enabled: true
                env:
                - name: ARGOCD_APPLICATION_NAMESPACES
                  value: '*'
              server:
                enabled: false
        - complianceType: musthave
----

.. Specify the `sourceNamespaces` to `*` in the default `AppProject` resource for deploying the Argo CD application into any namespace. View the following partial YAML file:

+
[source,yaml]
----
          objectDefinition:
            apiVersion: argoproj.io/v1alpha1
            kind: AppProject
            metadata:
              name: default
              namespace: openshift-gitops
            spec:
              clusterResourceWhitelist:
              - group: '*'
                kind: '*'
              destinations:
              - namespace: '*'
                server: '*'
              sourceRepos:
              - '*'
              sourceNamespaces:
              - '*'
        - complianceType: musthave
----

.. Grant access to the Argo CD application controller for the `cluster-admin` role. View the following partial YAML file:

+
[source,yaml]
----
          objectDefinition:
            apiVersion: rbac.authorization.k8s.io/v1
            kind: ClusterRoleBinding
            metadata:
              name: argo-admin
            subjects:
              - kind: ServiceAccount
                name: acm-openshift-gitops-argocd-application-controller
                namespace: openshift-gitops
            roleRef:
              apiGroup: rbac.authorization.k8s.io
              kind: ClusterRole
              name: cluster-admin
        pruneObjectBehavior: None
        remediationAction: enforce
        severity: medium
  remediationAction: enforce
----

.. Apply the YAML file sample by running the following command:

+
[source,bash]
----
oc apply -f policy-example.yaml
----
