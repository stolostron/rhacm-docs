[#gitops-deprecated]
= Deprecated APIs

[role="_abstract"]
Review deprecated GitOps APIs and the recommended migration path.

.MulticlusterApplicationSetReport

The `MulticlusterApplicationSetReport` API (`apps.open-cluster-management.io/v1alpha1`) has been deprecated and will be removed in a future release. This API was previously used to aggregate Argo CD application status from across managed clusters for the `ManifestWork`-based pull model. The associated Resource sync controller and Aggregation controller are also deprecated.

If you are using the `MulticlusterApplicationSetReport` API, plan to migrate to the {gitops} add-on with the *advanced pull model* (Argo CD Agent). The advanced pull model provides full real-time Application status through the native Argo CD agent/principal connection, including resource trees, logs, and detailed sync information - not just the overall health and sync status that the `ManifestWork`-based pipeline provided.
