[#gitops-enable-olm]
= Enabling a deployment based on {olm}

[role="_abstract"]
If you enable {gitops} add-on without the Argo CD Agent, enable a deployment based on {olm} for managing {ocp-short} managed clusters.

.Prerequisites

- All the managed clusters must be {ocp-short} clusters.

.Procedure

To enable a deployment based on {olm}, complete the following steps:

. On your hub cluster, create a `GitOpsCluster` resource with the `olmSubscription` value set to `enabled:true` in the `gitopsAddon` section. See the following YAML file sample:

+
[source,yaml]
----
apiVersion: apps.open-cluster-management.io/v1beta1
kind: GitOpsCluster
metadata:
  name: gitops-clusters-olm
  namespace: openshift-gitops
spec:
  argoServer:
    argoNamespace: openshift-gitops
  placementRef:
    kind: Placement
    apiVersion: cluster.open-cluster-management.io/v1beta1
    name: all-openshift-clusters
    namespace: openshift-gitops
  gitopsAddon:
    enabled: true
    olmSubscription:
      enabled: true
----

. Apply the YAML sample by running the following command:

+
[source,bash]
----
oc apply -f gitopscluster-example.yaml
----

.Additional resources

If you want to use {gitops} without the Argo CD Agent, see xref:../gitops/gitops_addon_without_argocd.adoc#enable-gitops-addon-without-argocd[Enabling {gitops} add-on without the Argo CD Agent].
