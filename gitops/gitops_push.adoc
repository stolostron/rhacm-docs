[#gitops-push]
= Using the Push model

[role="_abstract"]
Use the Push model so that the Argo CD server on the hub cluster deploys application resources directly to managed clusters.

*Required access:* Cluster administrator

Using the Push model, the Argo CD server on the hub cluster deploys the application resources directly on the managed clusters. The managed clusters do not run their own Argo CD instances.

*Note:* If you plan to use the *basic pull model* or *advanced pull model* with the {gitops} add-on, you do not need to complete this section. The GitOps add-on handles all cluster registration and Argo CD deployment automatically through the `GitOpsCluster` resource with `gitopsAddon.enabled: true`.

*Required access:* Cluster administrator

*Important:* {gitops-short} requires an *{ocp}* subscription. {acm-short} does not include this entitlement. See xref:../gitops/gitops_models.adoc#gitops-models[Understanding the Push and Pull models].
