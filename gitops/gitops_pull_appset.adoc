[#gitops-pull-appset]
= Deploying the Argo CD _ApplicationSet_ resource in any namespace (Technology Preview)

[role="_abstract"]
Deploy the Argo CD `ApplicationSet` resource in any namespace when you use the Pull model.

*Required access:* Cluster administrator

With the Argo CD pull model, you can create `ApplicationSet` resources in any namespace on your hub clusters.

*Prerequisites*

* Complete the procedures to deploy the {gitops} add-on with the `ManifestWork`-based pull model. See _Deploying Argo CD with the {gitops} add-on and `ManifestWork`-based pull model_.

*Technology Preview:* This feature is a Technology Preview feature.

See the following topics:

* xref:../gitops/gitops_pull_appset_enable.adoc#gitops-pull-appset-enable[Enabling the _ApplicationSet_ resource in any namespace]
* xref:../gitops/gitops_pull_appset_deploy.adoc#gitops-pull-appset-deploy[Deploying the _ApplicationSet_ resource for standard configurations]
