= Push model overview

[role="_abstract"]
With the Push model, the Argo CD server on the hub cluster deploys application resources directly to managed clusters. The managed clusters do not run their own Argo CD instances.

If you want to use the `ManifestWork`-based or Argo CD Agent-based model with the {gitops} add-on, see Pull model overview. The {gitops} add-on handles all cluster registration and Argo CD deployment automatically through the `GitOpsCluster` resource by setting `gitopsAddon.enabled: true`.

*Important:* {acm-short} does not include entitlements for {gitops-short}. You might need a separate {ocp} subscription for certain features. For more information, see the Self-managed Red Hat OpenShift subscription guide.
