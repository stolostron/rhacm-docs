[#gitops-push-overview]
= Push model overview

[role="_abstract"]
Use the Push model so that the Argo CD server on the hub cluster deploys application resources directly to managed clusters. The managed clusters do not run their own Argo CD instances.

If you want to use the *`ManifestWork`-based pull model* or *Argo CD Agent-based pull model* with the {gitops} add-on, see xref:../gitops/gitops_pull_overview.adoc#gitops-pull-overview[Pull model overview]. The {gitops} add-on handles all cluster registration and Argo CD deployment automatically through the `GitOpsCluster` resource by setting `gitopsAddon.enabled: true`.

*Important:* {acm-short} does not include entitlements for {gitops-short}. You might need a separate {ocp} subscription for certain features. For more information, see the link:https://www.redhat.com/en/resources/self-managed-openshift-subscription-guide[Self-managed Red Hat OpenShift subscription guide].

See the following topics to configure the Push model:

* xref:../gitops/gitops_push_register.adoc#gitops-push-register[Register {ocp-short} managed clusters to the {gitops} operator]
* xref:../gitops/gitops_push_register_non_ocp.adoc#gitops-push-register-non-ocp[Register non-{ocp-short} clusters to the {gitops} operator]
* xref:../gitops/gitops_push_deploy.adoc#gitops-push-deploy[Deploy an application with the Push model]
* xref:../gitops/gitops_push_service_account.adoc#gitops-push-service-account[Create a custom service account for Argo CD Push model]
