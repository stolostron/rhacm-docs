[#verify-gitops-addon]
= Verifying the {gitops-short} add-on functions

You can verify that your {gitops-short} add-on functions work by completing the following sections:

== Verifying the _GitOpsCluster_ status

To check the `GitOpsCluster` status, complete the following steps:

. View the `GitOpsCluster` resource status by running the following command:

+
[source,bash]
----
oc get gitopscluster <gitopscluster-name> -n openshift-gitops -o yaml
----

. Check the status conditions for specific failure information by running the following command:

+
[source,bash]
----
oc get gitopscluster <gitopscluster-name> -n openshift-gitops -o jsonpath='{.status.conditions}' | jq
----

See the following condition types to check:

* `Ready`: Overall `GitOpsCluster` health.
* `PlacementResolved`: `Placement` resource status.
* `ArgoServerVerified`: Whether the `ArgoCD` server pod was found in the specified namespace.
* `ApplicationSetResourcesReady`: Whether `ApplicationSet` ConfigMaps and RBAC resources were created successfully.
* `PolicyTemplateReady`: Whether the policy template was created successfully.
* `ClustersRegistered`: Cluster registration status.
* `AddOnDeploymentConfigsReady`: Whether `AddOnDeploymentConfigs` were created for all managed clusters. Only applies when the {gitops-short} add-on is enabled.
* `ManagedClusterAddOnsReady`: Whether `ManagedClusterAddOns` were created for all managed clusters. Only applies when the {gitops-short} add-on is enabled.
* `GitOpsAddonPrereqsReady`: Whether the addon prerequisites are set up, including RBAC resources and CA secrets. Only applies when the {gitops-short} add-on is enabled.
* `ArgoCDPolicyReady`: Whether the `ArgoCD` `Policy` was created for managing the `ArgoCD` custom resource on managed clusters. Only applies when the {gitops-short} add-on is enabled.
* `OLMSubscriptionReady`: Whether the OLM `Subscription` `AddOnTemplate` was created successfully. Only applies when OLM subscription mode is enabled.
* `AddOnTemplateReady`: Whether the dynamic `AddOnTemplate` was created for the `ArgoCD` agent mode. Only applies when the `ArgoCD` agent is enabled.
* `ArgoCDAgentPrereqsReady`: Agent prerequisites, if you have enabled the agent.
* `CertificatesReady`: TLS certificate status, if you have enabled the agent.
* `ManifestWorksApplied`: `ManifestWork` propagation status, if you have enabled the agent.


== Verifying the {gitops-short} add-on controller logs

To check the {gitops-short} add-on controller logs, complete the following steps:

. Go to the managed cluster.
. Check the {gitops-short} add-on controller logs by running the following command:

+
[source,bash]
----
oc logs -n open-cluster-management-agent-addon -l app=gitops-addon
----

== Verifying the {gitops-short} operator

To confirm that the {gitops-short} operator works, complete the following steps:

. Verify the operator is working by running the following command:

+
[source,bash]
----
oc get pods -n openshift-gitops-operator
----

. Check operator logs by running the following command:

+
[source,bash]
----
oc logs -n openshift-gitops-operator -l control-plane=controller-manager
----

== Verifying the _ArgoCD_ `Policy` status

To check that the `ArgoCD` `Policy` was created and is compliant, complete the following steps:

. On the hub cluster, check the `Policy` status by running the following command:

+
[source,bash]
----
oc get policy <gitopscluster-name>-argocd-policy -n openshift-gitops
----

. View detailed `Policy` information by running the following command:

+
[source,bash]
----
oc describe policy <gitopscluster-name>-argocd-policy -n openshift-gitops
----
