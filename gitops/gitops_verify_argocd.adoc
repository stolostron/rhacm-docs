[#verify-argocd-agent]
= Verifying the Argo CD agent functions (Technology Preview)

If you are using the Argo CD agent, you can verify that the principal and agent components are working.

*Required access:* Cluster administrator

.Prerequisites

* You configured the {gitops-short} add-on with the Argo CD agent.

.Procedure

. On your hub cluster, verify that the agent principal is running. Run the following command:

+
[source,bash]
----
oc get pods -n openshift-gitops -l app.kubernetes.io/name=openshift-gitops-agent-principal
----

. On your managed cluster, verify that the agent is running. Run the following command:

+
[source,bash]
----
oc get pods -n openshift-gitops -l app.kubernetes.io/part-of=argocd-agent --context <managed-cluster-context>
----

. Verify that the `ManifestWork` status is set for the certificate authority (CA) propagation. Run the following command:

+
[source,bash]
----
oc get manifestwork -n <managed-cluster-name> argocd-agent-ca-propagation -o yaml
----
