[#verify-argocd-agent]
= Verifying the Argo CD agent function (Technology Preview)

When you use the Argo CD agent, verify that the principal and agent components are working. Complete the following steps:

. On the hub, verify the agent principal is running by running the following command:

+
[source,bash]
----
oc get pods -n openshift-gitops -l app.kubernetes.io/name=openshift-gitops-agent-principal
----

. On the managed cluster, verify the agent is running by running the following command:

+
[source,bash]
----
oc get pods -n openshift-gitops -l app.kubernetes.io/part-of=argocd-agent --context <managed-cluster-context>
----

. Verify that the `ManifestWork` status is set for the certificate authority (CA) propagation by running the following command:

+
[source,bash]
----
oc get manifestwork -n <managed-cluster-name> argocd-agent-ca-propagation -o yaml
----
