[#gitops-overview]
= GitOps overview

[role="_abstract"]
{ocp} GitOps and Argo CD are integrated with {acm}, with advanced features compared to the previous Application Lifecycle _Channel_ and _Subscription_ model.

GitOps integration with Argo CD development is active, and the large community that contributes feature enhancements and updates to Argo CD. By utilizing the {ocp-short} GitOps Operator, you can use the latest advancements in Argo CD development and receive support from the GitOps Operator subscription.

The `GitOpsCluster` controller automatically creates the following resources for each managed cluster selected by the `Placement` resource:

- `AddOnDeploymentConfig` resource in the managed cluster namespace
- `ManagedClusterAddOn` resource in the managed cluster namespace
- Dynamic `AddOnTemplate` for the `ArgoCD` agent mode
- `ArgoCD` cluster secrets configured for agent mode
- TLS certificates for agent-to-hub authentication
- `ManifestWork` resources to propagate hub CA certificates to managed clusters

The `GitOpsCluster` controller performs the following operations:

- Creates and automates PKI management 
- Creates `ArgoCD` cluster secrets configured for agent mode
- Deploys the Argo CD Agent on each selected managed cluster
