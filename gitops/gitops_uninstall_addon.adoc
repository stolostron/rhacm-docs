[#uninstall-gitops-addon]
= Uninstalling the {gitops-short} add-on

To completely uninstall the {gitops-short} add-on, complete the following steps. Do not skip or switch steps to prevent dependency issues during cleanup.

*Important:* The add-on framework runs clean up jobs on each managed cluster to remove ArgoCD custom resources, {olm} subscription resources, and operator resources before deletion. The uninstall might take several minutes. Do not remove finalizers before the clean up completes.

.Procedure

. Delete the `GitOpsCluster` resource. Run the following command:

+
[source,bash]
----
oc delete gitopscluster <name> -n openshift-gitops --ignore-not-found
----

. Delete the auto-generated `Policy` resources. Run the following command. Replace `<name>` with the name of the `Policy` resource:

+
[source,bash]
----
oc delete policy <name>-argocd-policy -n openshift-gitops --ignore-not-found
----

Delete the `PlacementBinding` resources. Run the following command. Replace `<name>` with the name of the `PlacementBinding` resource:

+
[source,bash]
----
oc delete placementbinding <name>-argocd-policy-binding -n openshift-gitops --ignore-not-found
----

+
*Note:* If the `Policy` is not deleted, it continues to enforce the `ArgoCD` custom resource on managed clusters even after the add-on is removed.

. Delete the `ManagedClusterAddOn` resource for each managed cluster. Run the following command. Replace `<managed_cluster_namespace>` with the namespace of the managed cluster:

+
[source,bash]
----
oc -n <managed_cluster_namespace> delete managedclusteraddon gitops-addon
----

+
*Note:* Wait for the `ManagedClusterAddOn` to be deleted. This might take 2 to 5 minutes:

+
[source,bash]
----
oc get managedclusteraddon -A | grep gitops-addon
----

. Verify that the `ManagedClusterAddOn` resources are removed from managed cluster namespaces. Run the following command. Replace `<managed-cluster-name>` with the name of the managed cluster:

+
[source,bash]
----
oc get managedclusteraddon gitops-addon -n <managed-cluster-name>
----

. If you enabled the agent mode, clean up the hub cluster agent resources. Run the following command. Replace `<managed-cluster-name>` with the name of the managed cluster:

+
[source,bash]
----
oc delete secret cluster-<managed-cluster-name> -n openshift-gitops --ignore-not-found
----
