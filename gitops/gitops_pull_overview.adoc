= Pull model overview

[role="_abstract"]
In the Pull model, the {gitops} add-on installs the {gitops-short} operator and an Argo CD instance on each managed cluster. Each instance synchronizes applications from Git repositories independently. {acm} supports the following two Pull variants:

* *Argo CD Agent-based pull*: Full, real-time application status on the hub cluster through a principal and agent architecture. Requires a Red Hat OpenShift Platform Plus subscription.
* *`ManifestWork`-based pull*: Aggregated overall health and synchronization status on the hub cluster by using the `ManifestWork` resource. Requires an {ocp} subscription.

*Important notes:* 

* {acm-short} does not include entitlements for {gitops-short}. You might need a separate {ocp} subscription for certain features. For more information, see the link:https://www.redhat.com/en/resources/self-managed-openshift-subscription-guide[Self-managed Red Hat OpenShift subscription guide].
* If you enable the {gitops-short} add-on by using the `GitOpsCluster` custom resource, the `GitOpsCluster` disables the Push model for all applications.
