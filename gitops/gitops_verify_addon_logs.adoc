[#verify-gitops-addon-controller-logs]
= Verifying the {gitops-short} add-on controller logs

[role="_abstract"]
To check the {gitops-short} add-on controller logs, complete the following steps:

.Procedure

. Go to the managed cluster. 

. Check the {gitops-short} add-on controller logs by running the following command:

+
[source,bash]
----
oc logs -n open-cluster-management-agent-addon -l app=gitops-addon
----
