= Enabling the progressive rollout strategy by using the _ApplicationSet_ resource

[role="_abstract"]
To enable the progressive rollout strategy with your `ApplicationSet` resource, complete the following steps:

.Procedure

. On your hub cluster, update the {gitops-short} operator instance configuration in the `openshift-gitops` namespace. 

. Enable the progressive syncs for the `ApplicationSet` resource by running the following command:

+
[source,bash]
----
oc -n openshift-gitops patch argocd openshift-gitops --type='merge' -p '{"spec":{"applicationSet":{"extraCommandArgs":["--enable-progressive-syncs"]}}}'
----

. Restart the `openshift-gitops-applicationset-controller` deployment in the `openshift-gitops` namespace. 

. Apply the updated {gitops-short} operator instance configuration to create a new rollout by running the following command: 

+
[source,bash]
----
oc -n openshift-gitops rollout restart deployment openshift-gitops-applicationset-controller
----
