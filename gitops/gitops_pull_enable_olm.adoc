[#gitops-pull-enable-olm]
= Enabling a deployment based on {olm}

[role="_abstract"]
For {ocp-short} managed clusters, enable {olm}-based deployment when add-on auto-detection of the cluster type is not working properly.

*Required access:* Cluster administrator

For {ocp-short} managed clusters, you can enable OLM-based deployment by adding `olmSubscription.enabled: true` to the `gitopsAddon` specification in case the add-on auto-detection of the cluster type is not working properly:

[source,yaml]
----
gitopsAddon:
  enabled: true
  olmSubscription:
    enabled: true
----
