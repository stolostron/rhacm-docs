= Subscription application displays incorrect warning message

[role="_abstract"]
When you deploy the Subscription application (Deprecated), it displays a warning message for the Subscription node in the _Application Topology_ page. If you check the Subscription node details, it incorrectly shows the `local-cluster` is offline.

Check the real status of the `local-cluster` by clicking *Infrastructure* > *Clusters* from the Console navigation.
