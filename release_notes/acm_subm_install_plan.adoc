= Submariner install plan limitation

[role="_abstract"]
The Submariner install plan does not follow the overall install plan settings. Therefore, the operator management screen cannot control the Submariner install plan. By default, Submariner install plans are applied automatically, and the Submariner add-on is always updated to the latest available version corresponding to the installed {acm-short} version. To change this behavior, you must use a customized Submariner subscription.
