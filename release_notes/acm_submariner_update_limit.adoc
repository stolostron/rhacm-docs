[#submariner-update-limit]
= Automatic update not working with custom _CatalogSource_ or _Subscription_

[role="_abstract"]
Submariner is automatically updated when {acm} is updated. The automatic update might fail if you are using a custom `CatalogSource` or `Subscription`.

.Procedure

* Set the `spec.subscriptionConfig.channel` field to `stable-0.15` in the `SubmarinerConfig` custom resource for each managed cluster.

* link:https://issues.redhat.com/browse/ACM-6068[ACM-6068]
