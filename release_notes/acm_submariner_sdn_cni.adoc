[#submariner-sdn-cni]
= Submariner only supports OpenShift SDN or OVN Kubernetes

[role="_abstract"]
Submariner only supports {ocp} clusters that use the OpenShift SDN or the OVN-Kubernetes Container Network Interface (CNI) network provider.
