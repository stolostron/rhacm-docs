[#errata-acm]
= Errata updates for {acm-short}

By default, Errata updates are automatically applied when released. The details are published here when the release is available. If no release notes are listed, the product does not have an Errata release at this time.

*Important:* For reference, Jira links and Jira numbers might be added to the content and used internally. Links that require access might not be available for the user. 

See link:../install/upgrade_hub.adoc#upgrading-by-using-the-operator[Upgrading by using the operator] for more information about upgrades.

*Important:* Cluster lifecycle components and features are within the {mce-short}, which is a software operator that enhances cluster fleet management. Release notes for {mce-short}-specific features are found in at link:../clusters/release_notes/mce_release_notes.adoc#mce-release-notes[Release notes for Cluster lifecycle with {mce-short}].

== Errata 2.12.3

* Delivers updates to one or more product container images.

* Fixes the console errors caused by a policy having an invalid structure. (link:https://issues.redhat.com/browse/ACM-16238[ACM-16238])

* Stores the correct {ocp-short} version to the database when a cluster gets imported to {acm-short}. (link:https://issues.redhat.com/browse/ACM-17553[ACM-17553])

* Allows virtual machine actions on remote clusters with signed certificates. (link:https://issues.redhat.com/browse/ACM-17065[ACM-17065])

* Preserves the node object even when the `ClusterInstance` gets deleted from the cluster management hub. (link:https://issues.redhat.com/browse/ACM-17877[ACM-17877])

* Prevents the same metric from getting reported multiple times and triggering a `PrometheusDuplicateTimestamps` alert by only reporting that metric one time with a count of the number of {ocp-short} templates with violations. (link:https://issues.redhat.com/browse/ACM-16014[ACM-16014])

* Stops the metrics collector from degrading the addon status when the collector receives the HTTP 409 error code from the hub cluster, which correctly loads metric samples and rejects duplicates from the payload.  (link:https://issues.redhat.com/browse/ACM-16493[ACM-16493])

* Corrects the `ACMRemoteWriteError` alert so that it accurately reports when there is a 20% error rate of remote writes. (link:https://issues.redhat.com/browse/ACM-18000[ACM-18000])

== Errata 2.12.2

* Delivers updates to one or more product container images.

* Ensures that the observability operator fails to reconcile if it cannot find the {acm-short} {product-version} version of the image from the `imagestream`.  (link:https://issues.redhat.com/browse/ACM-15525[ACM-15525])

* Configures the `alertmanager` high availability (HA) to make Prometheus send requests to all the `alertmanagers`. (link:https://issues.redhat.com/browse/ACM-16211[ACM-16211])

* Deletes the deployment of the `observability-observatorium-operator` and recreates the compact `statefulset`. (link:https://issues.redhat.com/browse/ACM-14867[ACM-14867])

* Checks for the existence of image pull secrets on the `serviceaccount` during the reconcile loop and updates the `serviceaccount` by replacing it with a `serviceaccount` without the `search-pull-secret` secret. (link:https://issues.redhat.com/browse/ACM-15056[ACM-15056])

* Reports the status of an existing subscription for the `OperatorPolicy`. (link:https://issues.redhat.com/browse/ACM-15394[ACM-15394])

* Changes the system so that the network time protocol (NTP) server specified in the `InfraEnv` gets used as a fallback. (link:https://issues.redhat.com/browse/ACM-16163[ACM-16163])

* Prevents buttons that check user permissions in namespaces from changing between `Enabled` and `Disabled` states. (link:https://issues.redhat.com/browse/ACM-16019[ACM-16019])

* Detects if the `MultiClusterHub` made any changes that need to be applied to the container images. (link:https://issues.redhat.com/browse/ACM-16517[ACM-16517])
