= Errata updates for {acm-short}

By default, Errata updates are automatically applied when released. The details are published here when the release is available. If no release notes are listed, the product does not have an Errata release at this time.

*Important:* For reference, Jira links and Jira numbers might be added to the content and used internally. Links that require access might not be available for the user. 

See link:../install/upgrade_hub.adoc#upgrading-by-using-the-operator[Upgrading by using the operator] for more information about upgrades.

*Important:* Cluster lifecycle components and features are within the {mce-short}, which is a software operator that enhances cluster fleet management. Release notes for {mce-short}-specific features are found in at link:../clusters/release_notes/mce_release_notes.adoc#mce-release-notes[Release notes for Cluster lifecycle with {mce-short}].

== Errata 2.13.6

* Delivers updates to one or more product container images.

* Fixes a problem with the `alertmanager-clientca-metric` `ConfigMap`, which resulted in Prometheus `"TargetDown"` alerts from HTTP 401 Unauthorized errors that were linked to missing or outdated bearer token configuration. 
link:https://issues.redhat.com/browse/ACM-20743[ACM-20743] 

== Errata 2.13.5

* Delivers updates to one or more product container images.

* Corrects the problem with the `MultiClusterHub` operator installation window missing the _Repository_ and _Source Code_ link for this version of the product. The expected repository link is link:https://github.com/open-cluster-management/multiclusterhub-operator[multiclusterhub-operator]. 
link:https://issues.redhat.com/browse/ACM-22364[ACM-22364]

* Fixes the `HostedCluster` update image function so that the upgrade option displays the available update versions in the console. 
link:https://issues.redhat.com/browse/ACM-23944[ACM-23944]

* Fixes an issue when using an application subscription with the `ObjectBucket` channel type where `kustomization` resources were not processed correctly. You can now deploy an application subscription in an `ObjectBucket` channel by using `kustomization`.
link:https://issues.redhat.com/browse/ACM-24089[ACM-24089]

* Resolves the Assisted Service pod encountering a `CrashLoopBackOff` state. Prevents panic from a nil pointer exception in the `assisted-service` container if there are hosts missing data about the installation disk. 
link:https://issues.redhat.com/browse/ACM-24232[ACM-24232]

* Improves performance and increases timeouts that caused a problem with the console due to a `CrashLoopBackOff` condition on the pods. 
link:https://issues.redhat.com/browse/ACM-24721[ACM-24721]

* Corrects a race condition in the observability `metric-collector` that occurred when you used multiple workers, which caused some metrics to be incorrectly collected, creating gaps in the metrics data. 
link:https://issues.redhat.com/browse/ACM-24922[ACM-24922]

== Errata 2.13.3

* Delivers updates to one or more product container images.

* Fixes a regression where the console proxy agent did not use the `NO_PROXY` variable, which caused Ansible Automation Template creation to fail with a proxy authentication error in environments using both `PROXY` and NO_PROXY.
link:https://issues.redhat.com/browse/ACM-20600[ACM-20600]

* Prevents the `Applications` list from crashing when the hub cluster self-management is disabled. 
link:https://issues.redhat.com/browse/ACM-20085[ACM-20085]

* Provides validation for the `Baseboard Management Controller Address` (BMC) address and an example of the BMC format when a new host gets added to the `infraenv` by using the BMC form. 
link:https://issues.redhat.com/browse/ACM-17263[ACM-17263]

* Fixes a TLS enforcement regression that prevented the GitOps server from connecting to managed clusters, which caused Argo CD applications to appear deleted by reverting the cluster secret TLS configuration to insecure mode. 
link:https://issues.redhat.com/browse/ACM-19579[ACM-19579]

* Optimizes the `klusterlet-addon-search` and `search-collector` pods to reduce CPU usage up to 60%. 
link:https://issues.redhat.com/browse/ACM-19926[ACM-19926]

* Filters out the custom condition types when reporting them to the `addon.open-cluster-management.io` resource. 
link:https://issues.redhat.com/browse/ACM-19714[ACM-19714]
