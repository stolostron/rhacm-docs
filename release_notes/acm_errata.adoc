[#errata-acm]
= Errata updates for {acm-short}

By default, Errata updates are automatically applied when released. The details are published here when the release is available. If no release notes are listed, the product does not have an Errata release at this time.

*Important:* For reference, Jira links and Jira numbers might be added to the content and used internally. Links that require access might not be available for the user. 

See link:../install/upgrade_hub.adoc#upgrading-by-using-the-operator[Upgrading by using the operator] for more information about upgrades.

*Important:* Cluster lifecycle components and features are within the {mce-short}, which is a software operator that enhances cluster fleet management. Release notes for {mce-short}-specific features are found in at link:../clusters/release_notes/mce_release_notes.adoc#mce-release-notes[Release notes for Cluster lifecycle with {mce-short}].

== Errata 2.13.3

* Delivers updates to one or more product container images.

* Disables the proxy agent that caused the error by being incompatible with `NO_PROXY` instead of bypassing the control for the proxy.  (link:https://issues.redhat.com/browse/ACM-20600[ACM-20600])

* Prevents the `Applications` list from crashing even when the hub cluster self-management gets disabled. (link:https://issues.redhat.com/browse/ACM-20085[ACM-20085])

* Provides validation for the `Baseboard Management Controller Address` (BMC) address and an example of the BMC format when a new host gets added to the `infraenv` by using the BMC form. (link:https://issues.redhat.com/browse/ACM-17263[ACM-17263])

* Disables the Transport Layer Security (TLS) and sets `insecure` to `true` for the Argo CD cluster secret. (link:https://issues.redhat.com/browse/ACM-20364[ACM-20364])

* Stops the enabling of the Transport Layer Security (TLS) and sets `insecure` to `true` for the Argo CD managed cluster connection secret. (link:https://issues.redhat.com/browse/ACM-19579[ACM-19579])

* Optimizes the `klusterlet-addon-search` and `search-collector pods` to reduce their CPU usage up to 60%. (link:https://issues.redhat.com/browse/ACM-19926[ACM-19926])

* Filters out the custom condition types when reporting them to the `addon.open-cluster-management.io` resource. (link:https://issues.redhat.com/browse/ACM-19714[ACM-19714])

== Errata 2.13.2

* Delivers updates to one or more product container images.

* Fixes the issue for {ocp} templates by having the `ConfigurationPolicies` choose an endpoint that supports the `watch` API. (link:https://issues.redhat.com/browse/ACM-18827[ACM-18827])

* Prevents the same metric from getting reported multiple times and triggering a `PrometheusDuplicateTimestamps` alert by only reporting that metric one time with a count of the number of {ocp} templates with violations.  (link:https://issues.redhat.com/browse/ACM-16014[ACM-16014])

* Finds the managed cluster with the label `local-cluster` set to `true` when checking for the subscription for the application clusters. (link:https://issues.redhat.com/browse/ACM-18538[ACM-18538])

* Resolves a compatibility issue that prevented the `MultiClusterObservability` custom resource definition (CRD) from being reapplied, which caused updates to get stuck. (link:https://issues.redhat.com/browse/ACM-19094[ACM-19094])
