= Virtualization known issues

Review the known issues for {acm-short} Virtualization capability. The following list contains known issues for this release, or known issues that continued from the previous release. 

For your {ocp} cluster, see link:https://docs.redhat.com/en/documentation/openshift_container_platform/4.20/html/release_notes/ocp-4-20-release-notes#ocp-release-known-issues_release-notes[{ocp-short} known issues]. 

For more about deprecations and removals, see xref:../release_notes/acm_deprecate_remove.adoc#deprecations-removals-acm[Deprecations and removals for {acm-short}].

See the following known issues and limitations that might occur while using {ocp-virt} with {acm-short}:

== {acm-short} Virtualization requires {ocp-virt} 4.20.1 or later

{acm-short} 2.15 Virtualization with {ocp-virt} 4.20 is not supported. You need to use {ocp-virt} 4.20.1 or later with {acm-short} 2.15.

== Search result for only virtual machine resources are displayed

After you enable fine-grained RBAC and attempt to search resources, only virtual machine resources in the `kubevirt.io` `ClusterRoles` are displayed and not other resources. To workaround this issue, disable the `fine-grained-rbac` feature. Complete the following steps:

. Disable `fine-grained-rbac` in the `MultiClusterHub` resource. 

.. Edit your `MultiClusterHub` resource by running the following command:

+
[source,bash]
----
oc edit mch -n open-cluster-management multiclusterhub
----

.. Edit to change the `configOverrides` specification from `enabled: true` to `enabled: false`. See the following example with the feature disabled:

+
[source,yaml]
----
    - configOverrides: {}
      enabled: false
      name: fine-grained-rbac
----
