= Fixed issues for {acm-short}

By default, fixed issues for _errata_ releases are automatically applied when released. The details are published here when the release is available. If no release notes are listed, the product does not have an errata release at this time.

*Important:* For reference, Jira links and Jira numbers might be added to the content and used internally. Links that require access might not be available for the user. Learn about the types of link:https://access.redhat.com/security/updates/advisory[errata releases] from Red Hat.

See link:../install/upgrade_hub.adoc#upgrading-by-using-the-operator[Upgrading by using the operator] for more information about upgrades.

*Important:* Cluster lifecycle components and features are within the {mce-short}, which is a software operator that enhances cluster fleet management. Release notes for {mce-short}-specific features are found in at link:../clusters/release_notes/mce_release_notes.adoc#mce-release-notes[Release notes for Cluster lifecycle with {mce-short}].

== Errata 2.14.1

* Delivers updates to one or more product container images.

* Adds a missing link to the operator source code and repository on the OperatorHub installation page. The 'annotation.repository' is updated to point to the correct repository URL.
link:https://issues.redhat.com/browse/ACM-24849[ACM-24849]

* Updates the console with a functional *Upgrade* button to start the process with the accurate version for upgrade availability.
link:https://issues.redhat.com/browse/ACM-23943[ACM-23943]

* Fixes pull model GitOps deployments that were stuck in a constant `Refreshing` state in the console to a `Stable` state. The `pull-integration-controller` clears the refresh annotation to prevent applications from getting stuck in a constant `Refreshing` status.
link:https://issues.redhat.com/browse/ACM-23908[ACM-23908]

* Updates validation logic to normalize user-provided CIDRs before comparison with the calculate one, which was a formatting issue in the assisted service validation function that caused failure from a mismatch between the cluster machine CIDR and the calculated CIDR during IPv6 installation. The validation failed when users provided uppercase letters, leading zeros, or both.
link:https://issues.redhat.com/browse/ACM-23289[ACM-23289]

* Reduces the excessive `Skipping this secret` logs in the `certificate-policy-controller` resource by logging parsing errors and moving logs about secrets without a certificate.
link:https://issues.redhat.com/browse/ACM-23248[ACM-23248]

* Fixes a race condition where a host that was added to a managed cluster was marked as `installed`, `Done` by Central Infrastructure Management before all of the Certificate Signing Requests were approved. Central Infrastructure Management now approves all Certificate Signing Requests for hosts added to a managed cluster before marking the host as completely installed (Done).
link:https://issues.redhat.com/browse/ACM-22786[ACM-22786]

* Fixes when a namespace containing a Go template string but no `namespaceSelector` was incorrectly determined to not have a namespace that is specified. The fix ensures that the namespace is correctly identified.
link:https://issues.redhat.com/browse/ACM-22702[ACM-22702]

* Fixes error where the `objectSelector` and `namespaceSelector` were used at the same time, and objects that were discovered by the `objectSelector` in specific namespaces were applied to all namespaces that were returned by the namespaceSelector. 
link:https://issues.redhat.com/browse/ACM-22676[ACM-22676]

* Corrects the faulty metric collection from Prometheus. When using multiple workers with race condition, some worker nodes collected the same metrics instead of distinct sets of metrics, and sent metrics to the hub cluster Observability configuration.
link:https://issues.redhat.com/browse/ACM-24921[ACM-24921]

* Fixes the `nmstatectl` binary missing for the s390x architecture, causing the `initrd` image to fail to read the binary. The `nmstatectl` is available and included for the s390x architecture. 
link:https://issues.redhat.com/browse/MGMT-21276[MGMT-21276]

* Corrects the static network configuration failure to apply on systems with multiple network interfaces that use full ISO, resulting in cluster deployment failure. The static network configuration is applied correctly on systems with multiple network interfaces that use full ISO.
link:https://issues.redhat.com/browse/MGMT-21688[MGMT-21688]
