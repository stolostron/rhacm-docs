[#policy-needs-subscription-admin]
= Policy resource not deployed unless by subscription administrator

[role="_abstract"]
The `policy.open-cluster-management.io/v1` resources are no longer deployed by an application subscription by default for {acm-short} version 2.4. `policy.open-cluster-management.io/v1` resources that were deployed by existing application subscriptions in previous {acm-short} versions remain, but are no longer reconciled with the source repository unless the application subscriptions are deployed by a subscription administrator.

.Procedure

* Deploy the application subscription as a subscription administrator. See link:../applications/allow_deny.adoc[Creating an allow and deny list as subscription administrator] for information.
