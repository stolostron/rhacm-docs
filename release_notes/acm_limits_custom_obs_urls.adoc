= Limitations for custom managed cluster Observatorium API or Alertmanager URLs

[role="_abstract"]
Custom Observatorium API and Alertmanager URLs only support intermediate components with TLS passthrough.

.Procedure

* Use separate sub-domains if both custom URLs are pointing to the same intermediate component because {ocp-short} routers do not support two separate route objects with the same host.
