= Imported managed clusters show a _Pending Import_ status

[role="_abstract"]
Managed clusters that are manually imported on the primary hub cluster show a `Pending Import` status when the activation data is restored on the passive hub cluster. For more information, see _Managed clusters connection using Managed Service Account_.
