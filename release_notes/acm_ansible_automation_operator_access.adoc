[#ansible-automation-operator-access]
= {aap-short} operator access {aap-short} outside of a proxy

[role="_abstract"]
The {aap} operator cannot access {aap-short} outside of a proxy-enabled {ocp-short} cluster.

.Procedure

* Install the {aap-short} within the proxy. See install steps that are provided by {aap-short}.
