= Console _Role Assignments_ page fails after you update from the {product-version-prev} to {product-version}

[role="_abstract"]
After you update {acm-short} {product-version-prev} to {acm-short} {product-version}, the *Role Assignments* page in the console fails to load.

This issue only impacts clusters that are updated from {product-version-prev} to {product-version}, not new installations of {acm-short} {product-version}.

This issue occurs because of changes in the `MulticlusterRoleAssignment` custom resource definition. The `clusterSelection.placements` field is now required. However, `MulticlusterRoleAssignment` resources that were created in {acm-short} {product-version-prev} do not have this field populated.

To resolve this issue, delete and recreate all `MulticlusterRoleAssignment` resources after updating.

.Procedure

. Export your existing `MulticlusterRoleAssignment` resources to back up all configurations.
. Delete the existing `MulticlusterRoleAssignment` resources. Run the following command:

+
[source,bash]
----
oc delete multiclusterroleassignment --all
----

. Recreate the resources with the required `clusterSelection.placements` field populated.
. Navigate to *User Management* > *Role Assignments* in the console to confirm that the page loads successfully without errors and check for your role assignments.
