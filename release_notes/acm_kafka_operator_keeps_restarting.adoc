= Kafka operator keeps restarting

[role="_abstract"]
In the Federal Information Processing Standard (FIPS) environment, the Kafka operator keeps restarting because of the out-of-memory (OOM) state.

.Procedure

* Set the resource limit to at least `512M`. For detailed steps on how to set this limit, see link:https://docs.redhat.com/en/documentation/red_hat_streams_for_apache_kafka/2.6/html/deploying_and_managing_amq_streams_on_openshift/index[Deploying and Managing AMQ Streams on OpenShift].

.Additional resources
