[#hub-managed-clusters-clock]
= Hub cluster and managed clusters clock not synced

[role="_abstract"]
Hub cluster and manage cluster time might become out-of-sync, displaying in the console `unknown` and eventually `available` within a few minutes. Ensure that the {ocp-short} hub cluster time is configured correctly. See link:https://docs.redhat.com/en/documentation/openshift_container_platform/4.20/html/installation_configuration/installing-customizing[Customizing nodes].
