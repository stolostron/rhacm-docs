= Hub cluster communication limitations

[role="_abstract"]
The following limitations occur if the hub cluster is not able to reach or communicate with the managed cluster:

.Procedure

. Import a managed cluster manually by using the command line interface or by using the *Run import commands manually* option in the console. You cannot create a new managed cluster by using the console.
. Use AppSub or the ArgoCD pull model if you deploy an Application or ApplicationSet by using the console, or if you import a managed cluster into ArgoCD. The hub cluster ArgoCD controller calls the managed cluster API server.
