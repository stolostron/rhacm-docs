= Errata updates

By default, Errata updates are automatically applied when released. The details are published here when the release is available. If no release notes are listed, the product does not have an Errata release at this time.

*Important:* For reference, Jira links and Jira numbers might be added to the content and used internally. Links that require access might not be available for the user. 

See link:../install/upgrade_hub.adoc#upgrading-by-using-the-operator[Upgrading by using the operator] for more information about upgrades.

== Errata 2.11.4

* Delivers updates to one or more product container images.

* Resolves how the policy shows an `unknown` status for the local cluster. (link:https://issues.redhat.com/browse/ACM-13720[ACM-13720])

* Prevents the `observability-rbac-query-proxy` pod from crashing with an unrecoverable error. (link:https://issues.redhat.com/browse/ACM-15051[ACM-15051])

* Renames managed clusters labels so that they no longer impact Prometheus. (link:https://issues.redhat.com/browse/ACM-14482[ACM-14482])

* Enables the operator to handle updates to the service accounts and pull secret resources by itself. (link:https://issues.redhat.com/browse/ACM-15056[ACM-15056]) 

* Makes the `OperatorPolicy` compliant so that it can approve all comma-separated values (CSVs) in the installation plan. (link:https://issues.redhat.com/browse/ACM-14540[ACM-14540]) 

* Updates the image, `osImageVersion`, in the infrastructure operator environment so that it can update the `isoDownloadURL`. (link:https://issues.redhat.com/browse/ACM-14600[ACM-14600])

* Sets the expiration time on the non-compliant `CertificatePoicies`. (link:https://issues.redhat.com/browse/ACM-14610[ACM-14610]) 

* Configures the `alertmanager` so that Prometheus can send requests to all `alertmanagers`. (link:https://issues.redhat.com/browse/ACM-16212[ACM-16212])
