= Uninstalling and reinstalling earlier versions with an update can fail

[role="_abstract"]
Uninstalling {acm-short} from {ocp-short} can cause issues if you later want to install earlier versions and then update. For instance, when you uninstall {acm-short}, then install an earlier version of {acm-short} and update that version, the update might fail. The update fails if the custom resources were not removed.

Follow the link:../get_started/cleanup_reinstall.adoc#cleanup-reinstall[Cleaning up artifacts before reinstalling] procedure to prevent this problem.
