[#configure-klusterlet-addons]
= Configure klusterlet add-ons

[role="_abstract"]
In {acm-short}, you can configure the following klusterlet add-ons to improve the performance and functionality of your managed clusters:

* application-manager
* cert-policy-controller
* cluster-proxy
* config-policy-controller
* governance-policy-framework
* hypershift-addon
* managed-serviceaccount
* multicluster-observability-addon
* search-collector
* submariner
* volsync
* work-manager
