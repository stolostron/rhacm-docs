= Cleaning up the source hub cluster

After you verify that the clusters migrated successfully and are fully operational on the target hub cluster, you must remove the migration-related resources from the source hub cluster. 

*Important:* The cleanup process is destructive and irreversible because it permanently deletes all `ManagedCluster` resources from the source hub cluster.

.Prerequisites

. Before you proceed, verify that common cluster operations, such as policy application and monitoring, are functioning correctly on the target hub.
//how?
 
.Procedure 

You need to remove the Argo CD applications that were used to manage the clusters on the source hub cluster. Then, delete `ClusterInstance` resources and verify that resources were removed. See the following procedure:

. On the source hub cluster, delete the `ClusterInstance` applications by running the following command:

+
[source,bash]
----
oc delete application clusterinstance-sno-clusters -n openshift-gitops
----

+
Deleting `ClusterInstance` resources triggers the `siteconfig` operator to clean up related resources, including `ClusterDeployment`, `ImageClusterInstall`, `BareMetalHost`, secrets, and the cluster namespace. 

+
For clusters that migrated successfully, the {global-hub} adds pause annotations to the `ClusterDeployment` and `ImageClusterInstall` resources. These annotations prevent the deletion of these resources from affecting the actual running clusters.


. On the source hub, delete the `ClusterInstance` resources by running the following command:

+
[source,bash]
----
oc delete clusterinstance <cluster_name> -n <cluster_namespace> --wait=false
----

. *Optional:* To delete multiple clusters simultaneously, run a loop script similar to the following example:

+
[source,bash]
----
for cluster in sno1 sno2 sno3; do
  echo "Deleting ClusterInstance: ${cluster}"
  oc delete clusterinstance ${cluster} -n ${cluster} --wait=false
done
----

. Verify that the namespaces and related resources associated with the migrated clusters have been removed from the source hub. Run the following command:

+
[source,bash]
----
oc get namespace -A | grep -E 'sno1|sno2|sno3'
----
+
If the cleanup is successful, the command returns no results for the specified clusters.
