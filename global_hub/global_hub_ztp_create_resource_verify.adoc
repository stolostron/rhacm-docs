= Verifying the migration resource status

[role="_abstract"]
After you apply the migration resource, verify the progress of the migration.

*Required access:* Cluster administrator

.Procedure

. Check the status of the `ManagedClusterMigration` resource by running the following command:

+
[source,bash]
----
oc get managedclustermigration ztp-sno-migration -n multicluster-global-hub -o yaml
----

. Review the `status` section of the output. The migration is complete when the status indicates that all clusters have reached the `Completed` stage.

See xref:../global_hub/global_hub_ztp_monitoring.adoc#ztp-monitor-migration[Monitoring migration progress] to check the migration status.
