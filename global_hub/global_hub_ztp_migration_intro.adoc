= {global-hub} managed cluster migration

Cluster migration enables you to move managed clusters from one {acm-short} hub cluster to another, providing an alternative to in-place upgrades. You can gradually migrate managed clusters and validate each status before decommissioning the original hub cluster. Zero Touch Provisioning (ZTP) migration facilitates the transfer of fully provisioned, bare-metal clusters, while maintaining cluster state, configuration, and {gitops-short} management throughout the transition.

*Required access:* Cluster administrator
