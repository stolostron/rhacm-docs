= {global-hub} managed cluster migration

You can use cluster migration to deploy a new {acm-short} hub cluster with your targeted hub cluster instead of using in=place upgrades. You can gradually migrate managed clusters, and validate each status before decommissioning the original hub cluster. Zero Touch Provisioning (ZTP) migration facilitates the transfer of fully provisioned, bare-metal clusters. Migration maintains the cluster state, configuration, and {gitops-short} management throughout the transition.
