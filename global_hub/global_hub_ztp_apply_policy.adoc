[#ztp-apply-policy-hub]
= Applying policy to the target hub cluster for migration

In Zero Touch Provisioning (ZTP) deployments, {acm-short} policies are managed through Argo CD applications. These policies control cluster configuration, compliance, and governance. You must apply policy applications to the target hub cluster before you create the migration resource. This sequence ensures that policies are ready to apply to clusters as soon as the migration completes.

.Prerequisites

* You have access to the source hub cluster and the target hub cluster by using the {ocp-short} command-line tool (`oc`).
* The `openshift-gitops` operator is installed on both hub clusters.

.Procedure

. On the source hub cluster, export the policy applications by running the following command:

+
[source,bash]
----
oc get application -n openshift-gitops -l app=policies -o yaml > policies-app.yaml
----

. Switch your command-line to the target hub cluster and apply the policy applications to the target hub cluster. Run the following command:

+
[source,bash]
----
oc apply -f policies-app.yaml
----

. Verify that the policy applications are synchronized and the policies are created. Run the following commands to check that policy applications are created and synced:

+
[source,bash]
----
oc get application -n openshift-gitops -l app=policies

oc get policy -A
----

Wait for all policy applications to show a healthy state before you proceed to the next migration process. This process might take one or two minutes.

*Important:* Do not create the migration resource until the policy applications are fully synchronized. If policies are missing during migration, the clusters might fail to reach a compliant state.

See the xref:../global_hub/global_hub_ztp_create_resource.adoc#ztp-create-migration-resource[Creating the migration resource] procedure for the next steps.
