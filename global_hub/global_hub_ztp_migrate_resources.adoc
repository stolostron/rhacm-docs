= Migrating to ClusterInstance resources

[role="_abstract"]
When existing managed clusters require ZTP standardization, the administrator migrates them to ClusterInstance resources to leverage centralized global hub management.

.Prerequisites
* Completion of the preparation steps.
* Namespaces for the target clusters exist on the managed hub.

.Procedure
. Create a `ClusterInstance` manifest for the managed cluster.
. Define the hardware and network specifications within the `spec` section of the `ClusterInstance` CR.
. Apply the manifest to the global hub cluster:
+
[source,bash]
----
oc apply -f <cluster_instance_file>.yaml
----
. Monitor the migration status through the Multicluster Global Hub agent.
. Verify that the `ClusterInstance` status reflects a `Completed` or `Ready` state.

.Results
The managed cluster is successfully associated with a `ClusterInstance` resource and is visible within the global hub inventory.
