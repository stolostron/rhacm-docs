= Preparing to migrate virtual machines between clusters

[role="_abstract"]
Migrating virtual machines helps you move resources during cluster upgrades, times when you need to clear a node for maintenance, or during configuration changes. When you enable migration, the {ocp-virt} is automatically installed on your managed clusters with the `acm/cnv-operator-install` label. The migration toolkit for virtualization is also installed on your hub cluster.

*Required access:* Cluster administrator

Before you perform migration operations or access the Fleet Virtualization console, ensure that the following requirements are met:

.Required roles table
|===
| Role | Location | Purpose
| `acm-vm-fleet:admin` | Hub cluster | Perform migration operations and access the Fleet Virtualization console.
| `acm-vm-extended:admin` | Source and target clusters | Manage virtual machine extended and related resources.
| `acm-vm-cluster-migration:view` | Target cluster | Perform mandatory cluster version and {ocp-virt} operator readiness checks.
|===

.Procedure

. Enable fine-grained RBAC on your clusters to assign and use the required roles. See link:../secure_clusters/fine_grain_rbac_enable.adoc#fine-grain-enable[Enabling fine-grained role-based access control for virtualization].
. Ensure you have access to the `openshift-cnv` namespace.
. Ensure you have the `kubevirt.io:admin` role on both the source and target clusters.
. Install the latest supported version of {ocp-short}. See the link:https://access.redhat.com/documentation/en-us/openshift_container_platform/[OpenShift Container Platform overview].
. Understand the required roles for migration operations and access to the Fleet Virtualization console. See the following table for more information about the required roles. For additional details about fine-grained roles and permissions, see the link:../secure_clusters/fine_grain_roles_descriptions.adoc#fine-grain-roles-descriptions[Fine-grained RBAC roles and descriptions] documentation.
. See xref:../migrate_virt_machines.adoc#migrate-virt-machines[Migrating virtual machines between clusters] to complete the migration procedure.
