[#acm-virt]
= Virtualization

Manage {ocp-virt} virtual machine resources across all the clusters that {acm-short} manages. 

To use virtualization capabilities in {acm-short}, ensure that a supported version of {ocp-short} and the {ocp-virt} operator is installed on the clusters that you want to manage. For {acm-short} 2.15, you need to use {ocp-virt} 4.20.1 or later.
 
To view `VirtualMachine` resources across all the clusters that {acm-short} manages, use the Search service to list and filter the `VirtualMachine` resources that are created with the {ocp-virt}. You can also enable the following actions from the {acm-short} console on your `VirtualMachine` resources:

- Start
- Stop
- Restart
- Pause
- Unpause
- Snapshot
