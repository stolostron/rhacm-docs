[#backup-config-policy-virt]
= Configuring backup policies for {ocp-virt}

[role="_abstract"]
Use OpenShift APIs for Data Protection to backup and restore virtual machines. After you back up the virtual machines, you can restore it on the hub cluster or managed clusters.

These {acm-short} policies for {ocp-virt-short} support the following backup and restore storage options:

* Container Storage Interface (CSI) backups
* Container Storage Interface (CSI) backups with DataMover

The following storage options are not supported for backup and restore of virtual machines:

* File system backup and restore
* Volume snapshot backups and restores

To configure the policies, and either enable a backup schedule or run a restore operation for a virtual machine, complete the following steps: 

.Procedure

. Back up and restore a virtual machine. See xref:../backup_virt_vm.adoc#backup-restore-vm[Backing up and restoring a virtual machine].
. Review the virtualization policies that are installed on the hub cluster. See xref:../backup_virt_policies.adoc#backup-virt-policies[Virtualization policies installed on the hub cluster].
. Define the policies with `ConfigMaps`. See xref:../backup_virt_configmaps.adoc#backup-virt-configmaps[Defining policies with _ConfigMaps_].
. Review the virtualization policy `ConfigMaps`. See xref:../backup_virt_configmaps_ref.adoc#backup-virt-configmaps-ref[Virtualization policy _ConfigMaps_].
