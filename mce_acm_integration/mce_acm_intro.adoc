= Integrate {mce-short} with {acm-short} 

[role="_abstract"]
If you are using {mce-short} stand-alone and then you install {acm-short}, you can access more multicluster management features, such as _observability_ and _policy_. You need to install {acm-short}. See the {acm-short} link:../get_started/get_started_acm.adoc#get-started-acm[Get started with {acm-short}] documentation. See link:../get_started/adv_config_install.adoc#advanced-config-hub[MultiClusterHub advanced configuration] for details about {acm-short} after you install.
