= {mce-short} with {acm-short} integration

[role="_abstract"]
If you are using {mce-short} and then you install {acm-short}, you can access more multicluster management features, such as _observability_ and _policy_. For integrated capability, see the following requirements:

* You need to install {acm-short}. See the {acm-short} link:../install/install_overview.adoc#installing[Installing and upgrading] documentation.
* See link:../install/adv_config_mce.adoc#advanced-config-hub[MultiClusterHub advanced configuration] for details about {acm-short} after you install.
