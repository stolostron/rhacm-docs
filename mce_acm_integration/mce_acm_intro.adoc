= Integrate {mce-short} with {acm-short} 

[role="_abstract"]
If you are using {mce-short} stand-alone and then you install {acm-short}, you can access more multicluster management features, such as _observability_ and _policy_. You need to install {acm-short}. See _Get started with {acm-short}_. See _MultiClusterHub advanced configuration_ for details about {acm-short} after you install.
