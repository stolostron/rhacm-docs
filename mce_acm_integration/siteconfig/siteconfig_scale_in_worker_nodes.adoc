[#scale-in-sno]
= Scale-in of a {sno} cluster with the {sco}

[role="_abstract"]
Scale-in of a {sno} cluster removes a worker node from a cluster that was installed by the {sco}.

Scale in your managed cluster that was installed by the {sco}. You can scale in your cluster by removing a worker node.

*Required access:* Cluster administrator
