= Reinstallation of a cluster with the {sco} (Technology Preview)

[role="_abstract"]
Reinstallation of a cluster with the {sco} requires that you enable the process and define a preservation mode.

Reinstall your clusters by using the {sco}. After enabling the reinstallation, you can define your desired preservation mode and if applicable, label your resources.

*Required access:* Cluster administrator
