[#ibio]
= {ibio}

[role="_abstract"]
The {ibio} completes and manages image-based cluster installations by using the same APIs as existing installation methods.

Install the {ibio} so that you can complete and manage image-based cluster installations by using the same APIs as existing installation methods.

For more information about, and to learn how to enable the {ibio}, see _Image-based installations for {sno}_.
