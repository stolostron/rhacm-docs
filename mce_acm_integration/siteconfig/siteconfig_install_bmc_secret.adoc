[#create-bmc-secret]
= Create the BMC secret

[role="_abstract"]
Create a secret to connect to your baseboard management controller (BMC). You need a secret to connect to your baseboard management controller (BMC). Complete the following steps to create a secret.

*Required access:* Cluster administrator

.Procedure

. Create a YAML file for the BMC secret. See the following sample file that is named `example-bmc-secret.yaml`:

+
[source,yaml]
----
apiVersion: v1
data:
  password: <password>
  username: <username>
kind: Secret
metadata:
  name: example-bmh-secret
  namespace: "example-sno"
type: Opaque
----
+
* Ensure that the `namespace` value matches the target namespace.

. Apply the file to create the resource. Run the following command on the hub cluster:

+
[source,terminal]
----
oc apply -f example-bmc-secret.yaml
----
