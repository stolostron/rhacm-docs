[#create-hcp-placement]
= Create the placement definition

[role="_abstract"]
Create a placement definition that specifies the managed cluster for the policy deployment. Complete the following procedure:

.Procedure

. Create the `Placement` definition that selects only the `local-cluster`, which is a hub cluster that is managed. Use the following YAML sample:
+
[source,yaml]
----
apiVersion: cluster.open-cluster-management.io/v1beta1
kind: Placement
metadata:
  name: policy-mce-hcp-autoimport-placement
  namespace: open-cluster-management-global-set
spec:
  tolerations:
    - key: cluster.open-cluster-management.io/unreachable
      operator: Exists
    - key: cluster.open-cluster-management.io/unavailable
      operator: Exists
  clusterSets:
    - global
  predicates:
    - requiredClusterSelector:
        labelSelector:
          matchExpressions:
            - key: local-cluster
              operator: In
              values:
                - "true"
----
. Run `oc apply -f placement.yaml -n <namespace>`, where `namespace` matches the namespace that you used for the policy that you previously created.
