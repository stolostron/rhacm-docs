= Bring hosted clusters to a {acm-short} hub cluster

[role="_abstract"]
If you have {mce-short} clusters that are hosting multiple _hosted clusters_, you can bring those hosted clusters to a {acm-short} hub cluster to manage with {acm-short} components, such as _Application lifecycle_ and _Governance_. Begin with learning from the _Run hosted control planes with {mce-short}_.
