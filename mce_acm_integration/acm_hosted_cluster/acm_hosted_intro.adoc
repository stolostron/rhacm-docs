[#hosted-acm]
= Hosted clusters with {acm-short}

[role="_abstract"]
If you have {mce-short} clusters that are hosting multiple _hosted clusters_, you can bring those hosted clusters to a {acm-short} hub cluster to manage with {acm-short} components, such as _Application lifecycle_ and _Governance_.

Begin with learning from the link:../clusters/about/mce_hcp_overview.adoc#mce-hcp-overview[About hosted control planes with {mce-short}] documentation.
