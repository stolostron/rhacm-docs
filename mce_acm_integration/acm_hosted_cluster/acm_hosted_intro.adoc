= Working with hosted clusters in {acm-short}

If you have {mce-short} clusters that are hosting multiple _hosted clusters_, you can bring those hosted clusters to a {acm-short} hub cluster to manage with {acm-short} components, such as _Application lifecycle_ and _Governance_.

Begin with learning from the link:../clusters/about/mce_hcp_overview.adoc#mce-hcp-overview[About hosted control planes with {mce-short}] documentation. Then, see the following procedures for managing hosted clusters with {acm-short}:

* xref:./acm_hcp_pattern_arch.adoc#hosted-pattern[Integrated {hcp} fleet management architecture pattern]
* xref:./acm_hosted_cluster/acm_discover_hosted.adoc#discover-hosted-acm[Discovering {mce-short} hosted clusters in {acm-short}]
* xref:./acm_hosted_cluster/acm_integrate_import_hcp.adoc#auto-import-hcp[Automating import for discovered hosted clusters]
* xref:./acm_hosted_cluster/acm_integrate_import_rosa.adoc#import-discover-rosa[Automating import for discovered {rosa} clusters]
* xref:./acm_hosted_cluster/acm_propagate_labels.adoc#propagate-hosted-labels[Label propagation for hosted clusters between {acm-short} and {mce-short} hub clusters]
