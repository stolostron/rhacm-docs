[#hcp-hosting-infra]
= {mce-short} hosting infrastructure

[role="_abstract"]
Deploy multiple {mce-short} clusters to serve as the physical hosting infrastructure for control planes. See the following functions of the {mce-short} hosting cluster:

* Provides {hcp} components with a smaller footprint than a full {acm-short} installation.
* Includes the management console and BareMetal infrastructure operators.
* Optimizes for hosting workloads rather than high-level fleet management.
