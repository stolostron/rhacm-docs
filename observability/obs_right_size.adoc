= Optimizing workloads by using right-sizing recommendations (Technology Preview)

The right-sizing feature compares real-time CPU and memory usage with the resource configuration you set and offers recommendations to optimize workloads on a namespace and cluster level.

With right-sizing, you can use infrastructure more efficiently, reduce costs, and ensure better performance across workloads by identifying over-provisioned or under-utilized resources across managed clusters.

*Required access:* Editor

[#right-size-prereq]
== Prerequisites

- The multicluster observability operator is enabled on the hub cluster.

[#enable-right-size-prereq]
== Enabling right-sizing recommendations

You can enable right-sizing recommendations by enabling the feature in the `MultiClusterObservability` custom resource on the hub cluster. Complete the following steps:

Run the following command to open the observability instance configuration:

[source,bash]
----
oc edit multiclusterobservability observability
----

. Add the following lines to the `spec` section of your `MultiClusterObservability` custom resource:

+
[source,yaml]
----
apiVersion: observability.open-cluster-management.io/v1beta2
kind: MultiClusterObservability
metadata:
  name: observability
spec:
  capabilities:
    platform:
      analytics:
        namespaceRightSizingRecommendation:
          enabled: true
. . .
----
+
You can set `enabled:` to `false` to disable right-sizing recommendations.

After enabling right-sizing recommendations, the following resources are created automatically:

The `rs-namespace-config` ConfigMap:: Stores configurations for placement and `PrometheusRule`.
The `rs-prom-rules-policy` policy:: Contains the Prometheus rules to evaluate resource usage.
The 
The `rs-placement` placement:: Determines target clusters based on label selectors.
The 
The `rs-policyset-binding` PlacementBinding:: Binds the policy and placement together.

You can view right-sizing recommendations by accessing the `ACM Right-Sizing Namespace` Grafana dashboard in the console.
