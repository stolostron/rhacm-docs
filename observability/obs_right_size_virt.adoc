= Enabling right-sizing for Virtualization workloads (Technology Preview)

Enable right-sizing for Virtualization to help you identify over-provisioned or under-utilized virtual machine resources across managed clusters.

You can implement right-sizing by enabling the feature in the `MultiClusterObservability` custom resource on the hub cluster.

*Required access:* Editor

.Prerequisites

- The multicluster Observability operator is enabled on the hub cluster.
- You have the {ocp-virt} operator installed your related managed cluster or hub cluster.

Complete the following steps to enable right-sizing for your virtual machines:

. Open the `observability` instance configuration. Run the following command:

+
[source,bash]
----
oc edit multiclusterobservability observability
----

. Add the following lines to the `spec` section of your `MultiClusterObservability` custom resource:

+
[source,yaml]
----
apiVersion: observability.open-cluster-management.io/v1beta2
kind: MultiClusterObservability
metadata:
  name: observability
spec:
  capabilities:
    platform:
      analytics:
        virtualizationRightSizingRecommendation:
          enabled: true
. . .
----
+
You can set the `enabled:` parameter for `virtualizationRightSizingRecommendation` to `false` to disable right-sizing for Virtualization.

After enabling right-sizing, the following resources are created automatically:

The `rs-virt-config` `ConfigMap`:: Stores virtual machine configurations for placement and `PrometheusRule`.
The `rs-virt-prom-rules-policy` `Policy`:: Contains the Prometheus rules to evaluate resource usage.
The `rs-virt-placement` `Placement`:: Determines target clusters based on label selectors.
The `rs-virt-policyset-binding` `PlacementBinding`:: Binds the policy and placement together.

. View right-sizing guides by accessing *RightSizing Recommendation* > *ACM Right-Sizing OpenShift Virtualization* from your Grafana dashboard.

+
*Note:* The CPU and memory information at the cluster level is displayed.

.. To view CPU and memory details, and past resource usage for your virtual machines, select the name of your virtual machine.
