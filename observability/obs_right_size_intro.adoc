= Right-sizing recommendations (Technology Preview)

The right-sizing feature compares real-time CPU and memory usage with the resource configuration that you set and offers guides to optimize workloads on a namespace and cluster level.

With right-sizing, you can use infrastructure more efficiently, reduce costs, and ensure better performance across workloads by identifying over-provisioned or under-utilized resources across managed clusters.
