= Enabling Perses dashboards with the multicluster observability add-on (Technology Preview)

[role="_abstract"]
Enable the Perses dashboards in the `MultiClusterObservability` custom resource to view hub cluster and managed cluster metrics in Perses dashboards from the {ocp-short} console.

In addition to Grafana, hub cluster and managed cluster metrics can be viewed in Perses dashboards in the {ocp-short} console. Perses is an open-source dashboard and visualization platform. The multicluster observability add-on renders observability dashboards through the Cluster Observability Operator (COO) console plugin.

*Required access:* Cluster administrator

.Prerequisites

* The observability service is enabled on your hub cluster. See xref:../observability/observability_enable.adoc#enabling-observability-service[Enabling the observability service].

* The Red Hat OpenShift Cluster Observability Operator is installed on your hub cluster. For more information, see link:https://docs.redhat.com/en/documentation/red_hat_openshift_cluster_observability_operator/1-latest/html-single/about_red_hat_openshift_cluster_observability_operator/index[Cluster Observability Operator overview].

* The multicluster observability add-on is enabled with platform metrics collection. Platform metrics collection must be enabled before you enable the UI capability. See xref:../observability/obs_enable_mcoa.adoc#enable-mcoa[Enabling the multicluster observability add-on].

.Procedure

. Enable Perses dashboards by adding the `ui` specification to the `platform.metrics` section of your `MultiClusterObservability` custom resource. Run the following command:

+
[source,bash]
----
oc patch mco observability -n open-cluster-management-observability --type=merge -p '{"spec":{"capabilities":{"platform":{"metrics":{"default":{"enabled":true},"ui":{"enabled":true}}}}}}'
----

+
Your `MultiClusterObservability` resource might resemble the following YAML file:

+
[source,yaml]
----
apiVersion: observability.open-cluster-management.io/v1beta2
kind: MultiClusterObservability
metadata:
  name: observability
spec:
  capabilities:
    platform:
      metrics:
        default:
          enabled: true
        ui:
          enabled: true
----

. Verify the enablement of Perses dashboards in the `MultiClusterObservability` resource. The command must return `true`. Run the following command:

+
[source,bash]
----
oc get mco observability -n open-cluster-management-observability -o jsonpath='{.spec.capabilities.platform.metrics.ui.enabled}{"\n"}'
----
