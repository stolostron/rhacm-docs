= Uninstalling the Grafana instance

[role="_abstract"]
When you do not need the Grafana instance, clean up the environment by running the uninstallation script.

*Required access:* Cluster administrator

.Procedure

. Run the `setup-grafana-dev.sh` script with the `--clean` flag to uninstall the Grafana instance and clean up the environment. When you run the script with the `--clean` flag, the following resources are deleted: `secret/grafana-dev-config`, `deployment.apps/grafana-dev`, `service/grafana-dev`, `ingress.extensions/grafana-dev`, and `persistentvolumeclaim/grafana-dev`.

----
./setup-grafana-dev.sh --clean
----
+
You might receive the following output:

+
[source,bash]
----
secret "grafana-dev-config" deleted
deployment.apps "grafana-dev" deleted
serviceaccount "grafana-dev" deleted
route.route.openshift.io "grafana-dev" deleted
persistentvolumeclaim "grafana-dev" deleted
oauthclient.oauth.openshift.io "grafana-proxy-client-dev" deleted
clusterrolebinding.rbac.authorization.k8s.io "open-cluster-management:grafana-crb-dev" deleted
----
