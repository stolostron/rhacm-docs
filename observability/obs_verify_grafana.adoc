= Verify the Grafana version

[role="_abstract"]
Verify the Grafana version that is currently deployed within the cluster environment. You can verify from the command line interface (CLI) or from the Grafana user interface. 

*Required access:* Cluster administrator

.Procedure

. Verify the Grafana version from the CLI:
.. Log in to your hub cluster. 
.. Access the terminal for the `observability-grafana` pod.
. To display the current Grafana version that is deployed within the cluster environment, run the following command:

+
[source,bash]
----
grafana-cli --version
----

. Verify the Grafana version from the Grafana console:
.. Log in to the Grafana console dashboard.
.. Navigate to the _Manage_ tab.
.. To view the version, scroll to the end of the page.
