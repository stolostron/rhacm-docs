[#view-devices]
= Viewing devices

To obtain more information about the devices in your inventory, you can use the {rhem} CLI.

[#view-device-prereqs]
== Prerequisites

* You must install the {rhem} CLI.

[#view-device-details]
== View device inventory and device details

View devices in your device inventory.
Complete the following steps:

. View the devices in the device inventory by running the following command:

+
[source,bash]
----
flightctl get devices
----
+
See the following example output:
+
[source,bash]
----
NAME           ALIAS    OWNER   SYSTEM  UPDATED     APPLICATIONS  LAST SEEN
<device_name>  <none>   <none>  Online  Up-to-date  <none>        3 seconds ago
----

. View the details of this device in YAML format by running the following command:

+
[source,bash]
----
flightctl get device/<device_name> -o yaml
----
+
See the following example output:
+
[source,yaml]
----

[#view-labels]
== Viewing device and their labels using the CLI

View devices and their associated labels.
You can use labels to organize your devices and device fleets.
For more information, see the following sections:

* xref:../edge_manager/edge_mgr_manage_organize#device-labels[Labels and label selectors]
//TODO add link to Managing fleets

Complete the following steps:

. View devices in your inventory by using the `-o wide` option:

+
[source,bash]
----
flightctl get devices -o wide
----
+
See the following example output:
+
[source,bash]
----
NAME            ALIAS    OWNER   SYSTEM  UPDATED     APPLICATIONS  LAST SEEN      LABELS
<device1_name>  <none>   <none>  Online  Up-to-date  <none>        3 seconds ago  region=eu-west-1,site=factory-berlin
<device2_name>  <none>   <none>  Online  Up-to-date  <none>        1 minute ago   region=eu-west-1,site=factory-madrid
----

. View devices in your inventory with a specific label or set of labels by using the `-l <key=value>` option:

+
[source,bash]
----
flightctl get devices -l site=factory-berlin -o wide
----
+
See the following example output:
+
[source,bash]
----
NAME            ALIAS    OWNER   SYSTEM  UPDATED     APPLICATIONS  LAST SEEN      LABELS
<device1_name>  <none>   <none>  Online  Up-to-date  <none>        3 seconds ago  region=eu-west-1,site=factory-berlin
----
