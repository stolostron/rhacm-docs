[#edge-enable]
= Enabling the {rhem}

Enable the {rhem} to manage edge devices and applications at scale.

*Required access:* Cluster administrator

[#enable-preq]
== Prerequisites

* You need a {acm-short} hub cluster. 

[#enable-rhem-mch]
== Enabling the {rhem} from the `MultiClusterHub` resource

Patch the `MultiClusterHub` resource, then verify that {rhem} is enabled. Complete the following procedure:

. Set the `enabled` field to `true` in the `edge-manager-preview` entry of `spec.overrides.components` in the `Multiclusterhub` resource by running the following command:

+
[source,bash]
----
oc patch multiclusterhubs.operator.open-cluster-management.io multiclusterhub -n rhacm --type json --patch '[{"op": "add", "path":"/spec/overrides/components/-", "value": {"name":"edge-manager-preview","enabled": true}}]'
----

. Verify that the {rhem} is enabled by running the following command on the hub cluster:

+
[source,bash]
----
oc -n open-cluster-management get pods | grep flightctl-api
----

+
See the following example output:

+
[source,bash]
----
flightctl-api                    2/2     Running   0             43s
----

[#enable-rhem-plugin]
== Enabling the {rhem} console

Enable {rhem} in the {ocp-short} web console. Complete the following procedure:

. Open the console for editing by running the following command:

+
[source,bash]
----
oc edit console.v1.operator.openshift.io
----

. Enable the {rhem} console by adding `flightctl-plugin` to the `spec.plugins` section.
