[#deploy-update-service]
= Deploying the {update-service} instance

[role="_abstract"]
Deploy the {update-service} operator on your hub cluster to manage upgrades for disconnected clusters.

.Procedure

See the following process to deploy the {update-service} instance.

. In the {ocp-short} console, navigate to **Installed Operators** > **{update-service} Operator**.
. Select **Create Instance**.
. Define the instance using your local registry details:

+
[source,yaml]
----
apiVersion: update-service.openshift.io/v1beta2
kind: update-service
metadata:
  name: openshift-cincinnati-instance
  namespace: openshift-update-service
spec:
  registry: <registry-host-name>:<port>
  replicas: 1
  repository: ${LOCAL_REGISTRY}/ocp4/release
  graphDataImage: '<host-name>:<port>/cincinnati-graph-data-container'
----

. Select **Create** and verify the status with `oc get pods`.
