= Installing and upgrading {mce-short}

The {mce-short} is a software operator for managing clusters across clouds and data centers. It supports both {ocp-short} and Kubernetes cluster lifecycle management.

For full support information, see the link:https://access.redhat.com/articles/7120837[{mce-short} Support Matrix]. For life cycle information, see link:https://access.redhat.com/support/policy/updates/openshift[{ocp} Life Cycle policy].

*Important:* If you are using {acm-short}, then {mce} is already installed on the cluster.

*Deprecated:* {mce-short} 2.4 and earlier versions are no longer supported. The documentation might remain available, but without any errata releases for fixed issues or other updates.

*Best practice:* Upgrade to the most recent version.
