= Get started with {mce-short}

[role="_abstract"]
The {mce-short} is a software operator for managing clusters across clouds and data centers. It supports both {ocp-short} and Kubernetes cluster lifecycle management.

Install {mce-short} through {olm}, which manages the installation, update, and removal of components. You can install while connected online or in a disconnected environment.

Access APIs for cluster lifecycle management with the {mce-short}. Discover APIs from the console by using the API Explorer or from the command line.

The release image identifies the version of the {ocp-short} image that is used to create the cluster. When you create a cluster, you can select a release image from the list of available images.

For full support information, see the link:https://access.redhat.com/articles/7142379[{mce-short} Support Matrix]. For life cycle information, see link:https://access.redhat.com/support/policy/updates/openshift[{ocp} Life Cycle policy].

*Important:* If you are using {acm-short}, then {mce-short} is already installed on the cluster.

*Deprecated:* {mce-short} 2.7 and all earlier versions are no longer supported. The documentation might remain available, but without any errata releases for fixed issues or other updates. For lifecycle information, see link:https://access.redhat.com/support/policy/updates/openshift[{ocp} Life Cycle policy] and link:https://access.redhat.com/support/policy/updates/openshift_operators#platform-aligned[Platform-aligned operators].

*Best practice:* Update to the most recent version.
