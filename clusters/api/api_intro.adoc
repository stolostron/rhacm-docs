[#apis]
= APIs

*Deprecated:* The documentation for the APIs is deprecated. Use the _API Explorer_ in the console, or an `oc` command, to view current and supported APIs.

You can access APIs for cluster lifecycle management with the {mce-short}. *User required access:* You can only perform actions that your role is assigned. 

*Notes:* 

- You can also access all APIs from the integrated console. Select the *Administrator* perspective, then navigate to *Home* > *API Explorer* to explore API groups.

- For {ocp} versions earlier than version 4.20, select *local-cluster* from the cluster switcher. Then select *Home* > *API Explorer* to explore API groups.
