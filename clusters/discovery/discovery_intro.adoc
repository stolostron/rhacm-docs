[#discovery-intro]
= Discovery service

[role="_abstract"]
You can discover {ocp-short} clusters that are available from OpenShift Cluster Manager. After discovery, you can import your clusters to manage. The Discovery services uses the Discover Operator for back-end and console usage.

You must have an {ocm} credential. See Creating a credential for Red Hat {ocm} if you need to create a credential.

*Required access*: Administrator
