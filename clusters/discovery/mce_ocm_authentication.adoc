[#discovery-auth]
= Authenticating service accounts

To discover {ocp-short} clusters that are available from link:https://docs.redhat.com/en/documentation/openshift_cluster_manager/1-latest[OpenShift Cluster Manager], you need to authenticate with a service account. Note that {ocm} offline token is deprecated.

.Prerequisites
* You must have an {ocm} credential. See xref:../credentials/credential_ocm.adoc#creating-a-credential-for-openshift-cluster-manager[Creating a credential for {ocm}] if you need to create a credential. 

* Learn about creating an {ocm} service account at https://docs.redhat.com/en/documentation/red_hat_hybrid_cloud_console/1-latest/html/creating_and_managing_service_accounts/con-ciam-svc-acct-intro-creating-service-acct[Service accounts].

.Procedure

See the following procedure to authenticate with a service account.

. Create a new credentials secret as a service-account `client-id` and `client-secret` pair in the {mce-short} console.
. Specify a service account  `client-id` and `client-secret` pair so that the {mce-short} Discovery service can authenticate correctly and discover clusters.
. Set up the {rosa} `DiscoveredCluster` resource for import as a managed cluster. The {rosa} import flow that is initiated uses the service-account credentials authenticate and import the cluster.

.List of the deployed components
|===
| Role | Access permissions 

|{ocm} cluster autoscaler editor	
|Perform update operations on the cluster autoscaler

|{ocm} cluster editor	
|Perform update operations on clusters

|{ocm} cluster provisioner	
|Perform provision operations on clusters

|{ocm} cluster viewer	
|Perform read operations on clusters

|{ocm} IdP editor	
|Perform update operations on IdPs

|{ocm} machine pool editor	
|Perform update operations on machine pools

|{ocm} organization administrator	
|Perform all available operations on the associated organization's clusters

|Subscriptions viewer	
|Perform read operations on any Subscriptions resource.
