[#discovery-import]
= Enabling a discovered cluster for management

[role="_abstract"]
Automatically import supported clusters into your hub cluster with the `Discovery-Operator` for faster cluster management, without manually importing individual clusters. The following procedure is an example of how to import your discovered {rosa} and hosted control planes clusters automatically by using the `Discovery-Operator`. You can import from the console or from the command-line interface.

*Required access:* Cluster administrator

.Prerequisites

* Discovery is enabled by default. If you changed default settings, you need to enable Discovery.
* You must set up the {rosa} command-line interface. See link:https://docs.redhat.com/en/documentation/red_hat_openshift_service_on_aws/4/html/rosa_cli/rosa-get-started-cli#rosa-get-started-cli[Getting started with the {rosa} CLI] documentation.

Read the following topics to learn how to import your discovered {rosa} and hosted control plane clusters automatically:

* xref:../discovery/enable_discovery_console.adoc#discovery-import-console[Importing discovered {rosa} and hosted control plane clusters by using the console]
* xref:../discovery/enable_discovery_cli.adoc#discovery-import-cli[Importing discovered {rosa} and hosted control plane clusters by using the CLI]

*Important:* For other Kubernetes providers, you must import these infrastructure provider `DiscoveredCluster` resources manually. Directly apply Kubernetes configurations to the other types of `DiscoveredCluster` resources. If you enable the `importAsManagedCluster` field from the `DiscoveredCluster` resource, it is not imported due to the Discovery webhook.
