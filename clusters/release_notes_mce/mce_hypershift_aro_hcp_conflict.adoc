= HyperShift conflict when creating Azure Red Hat OpenShift {hcp} clusters with Cluster API Provider for Azure

[role="_abstract"]
You might not be able to create Azure Red Hat OpenShift {hcp} clusters by using Cluster API Provider for Azure if the `hypershift` and `cluster-api` controllers are running at the same time. To resolve the issue, complete the following steps:

.Procedure

. Disable the `hypershift` component. Run the following command:

+
[source,bash]
----
oc patch mce multiclusterengine --type=merge -p "{\"spec\":{\"overrides\":{\"components\":$(oc get mce multiclusterengine -o json | jq -c '.spec.overrides.components | map(if .name == "hypershift" then .enabled = false else . end)')}}}"
----

. Disable the `hypershift-local-hosting` component. Run the following command:

+
[source,bash]
----
oc patch mce multiclusterengine --type=merge -p "{\"spec\":{\"overrides\":{\"components\":$(oc get mce multiclusterengine -o json | jq -c '.spec.overrides.components | map(if .name == "hypershift-local-hosting" then .enabled = false else . end)')}}}" 
----
