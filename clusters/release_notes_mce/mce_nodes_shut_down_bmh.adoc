= Nodes shut down after removing `BareMetalHost` resource

[role="_abstract"]
If you remove the `BareMetalHost` resource from a hub cluster, the nodes shut down.

.Procedure

You can manually power on the nodes again.

link:https://issues.redhat.com/browse/ACM-15319[ACM-15319]
