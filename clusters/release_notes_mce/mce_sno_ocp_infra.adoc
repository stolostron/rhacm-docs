= {sno} cluster installation requires matching {ocp-short} with {infra}

[role="_abstract"]
If you want to install a {sno} cluster with an {ocp} version before 4.19, your `InfraEnv` custom resource and your booted host must use the same {ocp-short} version that you are using to install the {sno} cluster. The installation fails if the versions do not match.

.Procedure

To work around the issue, edit your `InfraEnv` resource before you boot a host with the Discovery ISO, and include the following content. Replace `<4.x>` with the `osImageVersion` that you want to install:

[source,yaml]
----
apiVersion: agent-install.openshift.io/v1beta1
kind: InfraEnv
spec:
  osImageVersion: "<4.x>"
----
