= ManagedClusterSet API specification limitation

[role="_abstract"]
The `selectorType: LaberSelector` setting is not supported when using the Clustersets API. The `selectorType: ExclusiveClusterSetLabel` setting is supported. Use the _API Explorer_ in the console, or an `oc` command, to view current and supported APIs.
