[#managedclusterset-api-limitation]
= ManagedClusterSet API specification limitation

[role="_abstract"]
The `selectorType: LaberSelector` setting is not supported when using the link:../api/clusterset.json.adoc#clustersets-api[Clustersets API]. The `selectorType: ExclusiveClusterSetLabel` setting is supported.
