[#non-ocp-pod-logs]
= Non-{ocp-short} managed clusters require _ManagedServiceAccount_ or _LoadBalancer_ for pod logs

[role="_abstract"]
The `ManagedServiceAccount` and cluster proxy add-ons are enabled by default in {acm-short} version 2.10 and newer. If the add-ons are disabled after upgrading, you must enable the `ManagedServiceAccount` and cluster proxy add-ons manually to use the pod log feature.
//potentially out of date--bcs 9/15

.Procedure

. See _ManagedServiceAccount add-on_ in link:../../clusters/get_started/adv_config_install.adoc#advanced-config-engine[Advanced configuration] to enable the `ManagedServiceAccount`.

. See link:../../clusters/cluster_lifecycle/cluster_proxy_addon_config.adoc#config-cluster-proxy-addon[Configuring cluster proxy add-ons] to enable a cluster proxy add-on.
