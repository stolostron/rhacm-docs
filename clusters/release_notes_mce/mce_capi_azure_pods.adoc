= Cluster API and Cluster API Provider for Azure deployments not creating pods

[role="_abstract"]
When you deploy `cluster-api` and `cluster-api-provider-azure` components, the Cluster API controllers might not create pods.

.Procedure

To work around the issue, complete the following steps:

. Verify that the `cluster-api` component is enabled. Run the following command:

+
[source,bash]
----
oc get mce multiclusterengine -o json | \
  jq -r '.spec.overrides.components[] | select(.name | contains("cluster-api"))'
----

. Check if the `hypershift` component is causing a conflict. Run the following command to check if the `READY` status is `0/1`: 

+
[source,bash]
----
oc get deployment -n hypershift
----

. If the status is `0/1`, force {mce-short} reconciliation. Run the following command:

+
[source,bash]
----
oc annotate mce multiclusterengine force-reconcile=$(date +%s) --overwrite
----
