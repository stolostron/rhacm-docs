= _ClusterCurator_ status stuck when upgrading the hub cluster

[role="_abstract"]
When you use the `ClusterCurator` resource to upgrade the hub cluster, the `ClusterCurator` status becomes stuck, even if the upgrade is successful. During upgrade, the hub cluster reboots, which stops the `Job` resource pod monitoring.

.Procedure

* To work around the issue, manually upgrade the hub cluster. If you already used the cluster curator to upgrade the hub cluster, you must delete the `ClusterCurator` resource hub cluster namespace so that future upgrades appear in the console.
