[#recreated-hive-clusters]
= Unclaimed Hive clusters recreated during ClusterPool custom resource definition changes

[role="_abstract"]
During a {mce-short} upgrade or modification to the `ClusterPool` custom resource definition, Hive might delete and re-create all unclaimed clusters. This is expected behavior and ensures that unclaimed clusters reflect the latest configuration defined in the updated `ClusterPool` resource specification.

link:https://issues.redhat.com/browse/ACM-21686[ACM-21686]
