[#hibernate-cluster-cli]
= Hibernate a cluster by using the command line interface

[role="_abstract"]
Hibernate a cluster that {mce-short} created so that the cluster uses fewer resources.

.Procedure

. Run the following command to edit the settings for the cluster that you want to hibernate. Replace `name-of-cluster` with the name of the cluster. Replace `namespace-of-cluster` with the namespace of the cluster:

+
[source,bash]
----
oc edit clusterdeployment <name-of-cluster> -n <namespace-of-cluster>
----

. Change the value for `spec.powerState` to `Hibernating`.
. Run the following command to view the status of the cluster:

+
[source,bash]
----
oc get clusterdeployment <name-of-cluster> -n <namespace-of-cluster> -o yaml
----
+
When hibernation is complete, the value of the type for the cluster is `type=Hibernating`.
