[#resume-hibernate-cluster-console]
= Resume a hibernating cluster by using the console

[role="_abstract"]
Resume normal operation of a hibernating cluster by using the console.

.Procedure

. From the navigation menu, select *Infrastructure* > *Clusters*. Ensure that the *Manage clusters* tab is selected.
. Select *Resume cluster* from the *Options* menu for the cluster that you want to resume.
. To resume multiple clusters, select the clusters on the *Clusters* page, then select *Actions* > *Resume clusters*.
+
The status for the cluster on the *Clusters* page is `Ready` when the process completes.
