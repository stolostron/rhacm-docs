[#configure-custom-clusterclaims-sync]
= Configure custom ClusterClaim synchronization

[role="_abstract"]
If you are managing `ClusterClaim` resources, configure the `KlusterletConfig` API to change the number of `ClusterClaim` resources that are synchronized.

.Procedure

. Create a `KlusterletConfig` and set `clusterClaimConfiguration.maxCustomClusterClaims` to your desired value. The maximum value is `100`. See the following example:

+
[source,yaml]
----
kind: KlusterletConfig
apiVersion: config.open-cluster-management.io/v1alpha1
metadata:
  name: klusterlet-cluster-claim-config
spec:
  clusterClaimConfiguration:
    maxCustomClusterClaims: 30
----

. Add an annotation to refer to the `KlusterletConfig` in the `ManagedCluster` resource. Run the following command:

+
[source,bash]
----
oc annotate managedcluster <cluster-name> agent.open-cluster-management.io/klusterlet-config="klusterlet-cluster-claim-config"
----

+
After adding the annotation, your `ManagedCluster` resource resembles the following example:

+
[source,yaml]
----
apiVersion: cluster.open-cluster-management.io/v1
kind: ManagedCluster
metadata:
  annotations:
   agent.open-cluster-management.io/klusterlet-config: klusterlet-cluster-claim-config
  name: cluster1
spec:
  hubAcceptsClient: true
  leaseDurationSeconds: 60
----
