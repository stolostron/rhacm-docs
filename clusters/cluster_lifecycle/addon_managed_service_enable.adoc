[#serviceaccount_enable]
= Enable the ManagedServiceAccount add-on

[role="_abstract"]
Enable the `ManagedServiceAccount` add-on for a hub cluster and a managed cluster.

*Required access:* Editor

.Prerequisites

* You need a supported {ocp} environment.
* You need the {mce-short} installed.

.Procedure

. Enable the `ManagedServiceAccount` add-on on hub cluster. See _ManagedServiceAccount add-on_ in xref:../get_started/adv_config_install.adoc#advanced-config-engine[Advanced configuration] to learn more.

. Deploy the `ManagedServiceAccount` add-on and apply it to your target managed cluster. Create the following YAML file and replace `target_managed_cluster` with the name of the managed cluster where you are applying the `Managed-ServiceAccount` add-on:

+
[source,yaml]
----
apiVersion: addon.open-cluster-management.io/v1alpha1
kind: ManagedClusterAddOn
metadata:
  name: managed-serviceaccount
  namespace: <target_managed_cluster>
spec:
  installNamespace: open-cluster-management-agent-addon
----

+
*Note:* The `spec.installNamespace` field is deprecated. See link:../../mce_release_notes/mce_deprecate_remove.adoc#deprecations-removals-cluster-mce[Product deprecations and removals] to learn more.

. Run the following command to apply the file:

+
----
oc apply -f -
----

+
You have now enabled the `ManagedServiceAccount` plug-in for your managed cluster. See xref:../cluster_lifecycle/addon_managed_service_create.adoc#serviceaccount_create[Create a ManagedServiceAccount] to configure a `ManagedServiceAccount`.
