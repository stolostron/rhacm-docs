= {aap-short} for cluster management

[role="_abstract"]
{mce-short} is integrated with {aap} so that you can create prehook and posthook Ansible job instances that run before or after you create or upgrade clusters. You can automate managed cluster and hosted cluster lifecycle actions with Automation templates and the `ClusterCurator` resource.

Configuring prehook and posthook jobs for cluster destroy and cluster scale actions on managed clusters is not supported.

*Required access:* Cluster administrator
