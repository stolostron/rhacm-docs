[#taints-tolerations]
= Taints and tolerations

[role="_abstract"]
Taints on a managed cluster prevent most placements from selecting it. Tolerations on a placement allow it to select clusters with matching taints. By default, placements do not select managed clusters that have taints.

You can control which placements can select your managed clusters by using taints and tolerations. This mechanism is useful when you want to restrict certain clusters to specific workloads.

*Important:* When a cluster has a taint, only placements with matching tolerations can select that cluster. This filtering happens automatically to protect workloads from being deployed to clusters that might not be suitable. For example, if a managed cluster becomes unreachable or unavailable, built-in taints are automatically applied to prevent new workloads from being placed on that cluster until it recovers.
