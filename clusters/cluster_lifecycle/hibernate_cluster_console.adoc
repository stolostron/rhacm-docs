[#hibernate-cluster-console]
= Hibernate a cluster by using the console

[role="_abstract"]
Hibernate a cluster that {mce-short} created so that the cluster uses fewer resources.

.Procedure

. From the navigation menu, select *Infrastructure* > *Clusters*. Ensure that the *Manage clusters* tab is selected.
. Select *Hibernate cluster* from the *Options* menu for the cluster.
+
*Note:* If the *Hibernate cluster* option is not available, you cannot hibernate the cluster. This situation can occur when the cluster is imported and was not created by {mce-short}.
. To hibernate multiple clusters, select the clusters on the *Clusters* page, then select *Actions* > *Hibernate clusters*.
+
The status for the cluster on the *Clusters* page is `Hibernating` when the process completes.
