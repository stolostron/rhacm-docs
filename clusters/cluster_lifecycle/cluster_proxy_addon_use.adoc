[#access-managed-cluster-kube-apiserver]
= Access the managed cluster `kube-apiserver` resource to gather, configure, and view data

[role="_abstract"]
Use cluster proxy add-ons to access the managed cluster `kube-apiserver` resource or managed cluster services to gather specific resources, get logs, and view data in the console. Access the `kube-apiserver` by using three different methods.

*Required access:* Editor

.Prerequisites

* You must xref:../cluster_lifecycle/cluster_proxy_addon_settings.adoc#cluster-proxy-addon-settings[configure proxy settings for cluster proxy add-ons].

.Additional resources

* xref:../cluster_lifecycle/cluster_proxy_addon_use_managed_token.adoc#gather-data-managed-token[Gather data with a managed cluster user token]
* xref:../cluster_lifecycle/cluster_proxy_addon_use_hub_token.adoc#gather-data-hub-token[Gather data with a hub cluster user token]
* xref:../cluster_lifecycle/cluster_proxy_addon_use_services.adoc#gather-data-managed-cluster-services[Gather data with managed cluster services]
