= Specifying release images

When you create a cluster on a provider by using {mce}, you need to specify a release image to use for your new cluster. To specify a release image, you need access to the GitHub repository for the YAML files that reference the release images. See link:https://github.com/stolostron/acm-hive-openshift-releases[acm-hive-openshift-releases] for those images.

. You need to locate the release image that you want to use for your cluster. See xref:../cluster_lifecycle/release_images_locate.adoc#cluster-image-set[Locating _ClusterImageSets_] for information about how to locate the release image you want to use.

. Next you need to configure a _ClusterImageSet_ resource to use the release image that you want. See xref:../cluster_lifecycle/release_images_config.adoc#config-cluster-image-set[_ClusterImageSets_ configuration] for information about how to configure a _ClusterImageSet_ resource.

. Next you can create a cluster on an architecture that is different from the architecture of the hub cluster. See xref:../cluster_lifecycle/release_images_cross_arch.adoc#manual-release-image-cross-arch[Creating a release image for a different architecture].
