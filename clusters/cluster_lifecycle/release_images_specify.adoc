= Specifying release images

When you create a cluster on a provider by using {mce}, specify a release image to use for your new cluster. To specify a release image, see the following topics:

* xref:../cluster_lifecycle/release_images_locate.adoc#cluster-image-set[Locating _ClusterImageSets_]
* xref:../cluster_lifecycle/release_images_config.adoc#config-cluster-image-set[Configuring _ClusterImageSets_]
* xref:../cluster_lifecycle/release_images_cross_arch.adoc#manual-release-image-cross-arch[Creating a release image to deploy a cluster on a different architecture]
