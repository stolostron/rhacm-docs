= Cluster update introduction

[role="_abstract"]
After you create {ocp} clusters that you want to manage with {mce-short}, you can use the {mce-short} console to update those clusters to the latest minor version that is available in the version channel that the managed cluster uses.

In a connected environment, the updates are automatically identified with notifications provided for each cluster that requires an update in the console. 

*Important:* You cannot update Red Hat OpenShift Kubernetes Service managed clusters or {ocp-short} managed clusters on Red Hat OpenShift Dedicated by using the {mce-short} console.
