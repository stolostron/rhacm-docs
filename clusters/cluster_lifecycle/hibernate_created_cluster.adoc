[#hibernating-a-created-cluster]
= Cluster hibernation

[role="_abstract"]
Hibernation reduces resource use for clusters that {mce-short} created so that you can lower provider costs by moving clusters in and out of a hibernating state.

A hibernating cluster requires significantly fewer resources than a running cluster. This feature applies only to clusters that {mce-short} created in the following environments:

* Amazon Web Services
* Microsoft Azure
* Google Cloud Platform

See the following documentation to hibernate and resume clusters:

* xref:../cluster_lifecycle/hibernate_cluster_console.adoc#hibernate-cluster-console[Hibernate a cluster by using the console]
* xref:../cluster_lifecycle/hibernate_cluster_cli.adoc#hibernate-cluster-cli[Hibernate a cluster by using the command line interface]
* xref:../cluster_lifecycle/resume_hibernate_cluster_console.adoc#resume-hibernate-cluster-console[Resume a hibernating cluster by using the console]
* xref:../cluster_lifecycle/resume_hibernate_cluster_cli.adoc#resume-hibernate-cluster-cli[Resume a hibernating cluster by using the command line interface]
