= Create a cluster with the CLI

The {mce} uses internal Hive components to create {ocp} clusters. See the following information to learn how to create clusters.

.Prerequisites

* Before you create a cluster with the CLI, see xref:../cluster_lifecycle/create_cluster_cli_prep.adoc#prepare-to-create-a-cluster-with-the-cli[Prepare to create a cluster with the CLI].

.Procedure

. Create a `ClusterDeployment` resource, which is a Hive resource that is used to control the lifecycle of a cluster. Go to the link:https://github.com/openshift/hive/blob/master/docs/using-hive.md#using-hive[Using Hive] documentation to create the `ClusterDeployment` custom resource and create an individual cluster.

. Create a `ClusterPool`` resource, which is also a Hive resource that is used to create multiple clusters. Go to the link:https://github.com/openshift/hive/blob/master/docs/clusterpools.md[Cluster Pools] documentation to create a cluster with the Hive `ClusterPool` API.
