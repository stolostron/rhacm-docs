= Import a managed cluster by using the CLI

After you install {mce}, you are ready to import a cluster and manage it by using the {ocp} CLI. Continue reading the following topics to learn how to import a managed cluster with the CLI by using the auto import secret, or by using manual commands.

* xref:../cluster_lifecycle/import_cli_prep.adoc#preparing-cluster-import[Prepare for cluster import]
* xref:../cluster_lifecycle/import_cli_auto_secret.adoc#importing-clusters-auto-import-secret[Import a cluster by using the auto import secret]
* xref:../cluster_lifecycle/import_cli_manual.adoc#importing-cluster-manual[Import a cluster manually]
* xref:../cluster_lifecycle/import_cli_klusterlet.adoc#importing-the-klusterlet[Import the klusterlet add-on]
* xref:../cluster_lifecycle/import_cli_remove.adoc#removing-imported-cluster-cli[Remove an imported cluster by using the command line interface]

*Important:* A hub cluster cannot manage a different hub cluster. A hub cluster is set up to automatically import and manage itself as a _local cluster_. You do not have to manually import a hub cluster to manage itself. If you remove a hub cluster and try to import it again, you need to add the `local-cluster:true` label.
