[#ansible-hosted-cluster-update]
= Run an {aap-short} job to update a hosted cluster

[role="_abstract"]
Run an {aap-short} job that updates a hosted cluster by editing the `ClusterCurator` resource of the hosted cluster that you want to update.

*Required access:* Cluster administrator

.Procedure

. Edit the `ClusterCurator` resource of the hosted cluster that you want to update. See the following example:

+
[source,yaml]
----
apiVersion: cluster.open-cluster-management.io/v1beta1
kind: ClusterCurator
metadata:
  name: my-cluster
  namespace: clusters
  labels:
    open-cluster-management: curator
spec:
  desiredCuration: upgrade
  upgrade:
    desiredUpdate: 4.17.1
    monitorTimeout: 120
    prehook:
      - name: Demo Job Template
        extra_vars:
          variable1: something-interesting
          variable2: 2
      - name: Demo Job Template
    posthook:
      - name: Demo Job Template
    towerAuthSecret: toweraccess
----
