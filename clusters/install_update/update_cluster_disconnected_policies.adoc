[#update-disconnect-cluster-policy]
= Updating disconnected clusters by using policies

[role="_abstract"]
If you use the {acm-short} hub cluster, which uses the `MultiClusterHub` operator to manage, update, and install hub cluster components, you can use the {update-service} and {acm-short} policies to update multiple clusters in a disconnected environment.

{update-service} is a separate operator and operand that monitors available versions for managed clusters and makes them accessible for updating in restricted networks.

{update-service} performs the following actions:

* Monitors update availability for disconnected clusters.
* Identifies updates mirrored to your local site by using the graph data file.
* Notifies you of available updates via the console.
