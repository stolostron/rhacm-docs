= Destroying a hosted cluster on OpenShift Virtualization

*Documentation deprecation notice:* The hosted control planes _documentation_ is deprecated and moving to the official {ocp-short} documentation. The component itself is not deprecated. Find the official documentation at link:https://docs.redhat.com/en/documentation/openshift_container_platform/4.17/html/hosted_control_planes/index[Hosted control planes overview] and use the version selector in the navigation to change versions of the documentation.

To destroy a hosted cluster and its managed cluster resource, complete the following steps:

. Delete the managed cluster resource on {mce-short} by running the following command:

+
----
oc delete managedcluster <cluster_name>
----

+
where `_cluster_name_` is the name of your cluster.

. Delete the hosted cluster and its back-end resources by running the following command:

+
----
hcp destroy cluster kubevirt --name $CLUSTER_NAME
----

+
Replace names where necessary.
