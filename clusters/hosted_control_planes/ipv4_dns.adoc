= Configuring DNS for an IPv4 network

*Documentation deprecation notice:* The hosted control planes _documentation_ is deprecated and moving to the official {ocp-short} documentation. The component itself is not deprecated. Find the official documentation at link:https://docs.redhat.com/en/documentation/openshift_container_platform/4.17/html/hosted_control_planes/index[Hosted control planes overview] and use the version selector in the navigation to change versions of the documentation.

This step is mandatory for both disconnected and connected environments in both virtual and bare metal environments. The key distinction between virtual and bare metal environment lies in the location where you configure the resources. In a bare-metal environment, use a solution like Bind rather than a lightweight solution like `dnsmasq`.

* To configure DNS for an IPv4 network on a virtual environment, see xref:../hosted_control_planes/config_ingress_dns_kubevirt.adoc#create-hosted-clusters-kubevirt-default-ingress-dns[Default ingress and DNS behavior].

* To configure DNS for an IPv4 network on bare metal, see xref:../hosted_control_planes/config_dns_bm.adoc#configure-dns-bm[Configuring DNS on bare metal].
