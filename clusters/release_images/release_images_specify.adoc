[#release-images-specify]
= Specify release images

[role="_abstract"]
When you create a cluster on a provider by using {mce}, you need to specify a release image to use for your new cluster.

.Prerequisites

* You need access to the GitHub repository for the YAML files that reference the release images. See link:https://github.com/stolostron/acm-hive-openshift-releases
[acm-hive-openshift-releases].

.Procedure

. Locate the release image that you want to use for your cluster. See xref:../release_images/release_images_locate.adoc#cluster-image-set[Locate _ClusterImageSets_] for information about how to locate the release image you want to use.

. Configure a _ClusterImageSet_ resource to use the release image that you want. See xref:../release_images/release_images_config.adoc#config-cluster-image-set[Configure _ClusterImageSets_] for information about how to configure a _ClusterImageSet_ resource.

. Create a cluster on an architecture that is different from the architecture of the hub cluster. See xref:../release_images/release_images_cross_arch.adoc#manual-release-image-cross-arch[Create a release image to deploy a cluster on a different architecture].
