= Getting started with {hcp} clusters with {mce-short}

With hosted control planes, you create control planes as pods on a management cluster without the need for dedicated virtual or physical machines for each control plane. {ocp-short} clusters can use standalone or hosted control planes.

* Standalone uses dedicated virtual or physical machines.

* Hosted creates control planes as pods on a management cluster, eliminating the need for dedicated virtual or physical machines for each control plane.

. Read more about hosted control planes from the official documentation:

link:https://docs.redhat.com/en/documentation/openshift_container_platform/4.18/html/hosted_control_planes/hosted-control-planes-overview[Hosted control planes overview].

. Find the requirements from link:https://docs.redhat.com/en/documentation/openshift_container_platform/4.18/html/hosted_control_planes/preparing-to-deploy-hosted-control-planes[Preparing to deploy hosted control planes].
