= Getting started with cluster management

The {mce-short} provides a simple way to manage multiple clusters across clouds and data centers. You can use it to deploy and manage {ocp-short} and Kubernetes clusters. Learn how to get started with certain use cases.

Each procedure includes prerequisites and steps to complete the task and is based in an {ocp-short} environment with the {mce-short} installed. If you later integrate with {acm-short}, you can use more features and capabilities.
