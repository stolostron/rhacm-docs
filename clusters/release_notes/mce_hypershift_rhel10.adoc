= HyperShift not supported on Red Hat Enterprise Linux 10 with certain feature gates

[role="_abstract"]
You cannot use enable the {hcp} feature on {ocp-short} version 4.22 clusters that run on Red Hat Enterprise Linux 10 if the `TechPreviewNoUpgrade` feature gate is enabled. 

.Procedure

If you attempt to enable {hcp} on these clusters, the clusters become unstable.

link:https://issues.redhat.com/browse/ACM-34084[ACM-34084]
