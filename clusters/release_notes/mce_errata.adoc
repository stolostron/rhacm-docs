= Errata updates for Cluster lifecycle with {mce-short}

For {mce-short}, the Errata updates are automatically applied when released.

If no release notes are listed, the product does not have an Errata release at this time.

*Important:* For reference, Jira links and Jira numbers might be added to the content and used internally. Links that require access might not be available for the user.

== Errata 2.8.4

* Delivers updates to one or more product container images.

* Fixes a YAML generation problem that prevented disabling of default network attachment during deployment of hosted clusters on {ocp-virt-short}.
(link:https://issues.redhat.com/browse/ACM-24960[ACM-24960])

* Improves performance and increases timeouts that caused a problem with the console due to a `CrashLoopBackOff` condition on the pods. (link:https://issues.redhat.com/browse/ACM-24721[ACM-24721])

* Corrects the problem with the `MultiClusterHub` operator installation window missing the _Repository_ and _Source Code_ link for this version of {mce-short}. The expected repository link is link:https://github.com/open-cluster-management/backplane-operator[backplane-operator]. (link:https://issues.redhat.com/browse/ACM-22364[ACM-22367])
