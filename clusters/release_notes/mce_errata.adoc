= Errata updates for Cluster lifecycle with {mce-short}

For {mce-short}, the Errata updates are automatically applied when released.

If no release notes are listed, the product does not have an Errata release at this time.

*Important:* For reference, Jira links and Jira numbers might be added to the content and used internally. Links that require access might not be available for the user.

== Errata 2.8.5

* Delivers updates to one or more product container images.

* Fixes an issue where `cluster-manager` pods that are within `multicluster-engine` were continuously reporting `OOMKilled` status with no apparent resource scarcity on the cluster. 
link:https://issues.redhat.com/browse/ACM-21304[ACM-21304]

* Resolves a crash in the klusterlet agent that was caused by a concurrent map access race condition in the resource cache during managed cluster importing. 
link:https://redhat.atlassian.net/browse/ACM-27019[ACM-27019]

* Resolves an installation console blockage that was caused by an immutable field change in `AgentClusterInstall`, which prevented the installation from proceeding.
link:https://redhat.atlassian.net/browse/ACM-27599[ACM-27599]


== Errata 2.8.4

The expected repository link is link:https://github.com/open-cluster-management/backplane-operator[backplane-operator]. link:https://issues.redhat.com/browse/ACM-22364[ACM-22367]
