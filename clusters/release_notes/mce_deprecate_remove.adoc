| None

| The `hubKubeAPIServerProxyConfig` field is deprecated in the `KlusterletConfig` spec.
| 2.7
| Use the `hubKubeAPIServerConfig.proxyURL` and `hubKubeAPIServerConfig.trustedCABundles` fields.

| None
