[#non-ocp-pod-logs]
= Non-{ocp-short} managed clusters require _ManagedServiceAccount_ or _LoadBalancer_ for pod logs

[role="_abstract"]
The `ManagedServiceAccount` and cluster proxy add-ons are enabled by default in {acm-short} version 2.10 and newer.

.Procedure

If the add-ons are disabled after upgrading, you must enable the `ManagedServiceAccount` and cluster proxy add-ons manually to use the pod log feature.

See _ManagedServiceAccount add-on_ in link:../../clusters/get_started/adv_config_install.adoc#advanced-config-engine[Advanced configuration] to learn how to enable `ManagedServiceAccount` and see link:../../clusters/cluster_lifecycle/cluster_proxy_addon_config.adoc#config-cluster-proxy-addon[Configuring cluster proxy add-ons] to learn how to enable a cluster proxy add-on.
