[#whats-new-mce]
= What's new for Cluster lifecycle with {mce-short}

Learn about new features for creating, importing, managing, and destroying Kubernetes clusters across various infrastructure cloud providers, private clouds, and on-premises data centers.

For full support information, see the link:https://access.redhat.com/articles/7086906[{mce-short} Support matrix]. For lifecycle information, see link:https://access.redhat.com/support/policy/updates/openshift[{ocp} Life Cycle policy].

*Important:* Cluster management supports all providers that are certified through the Cloud Native Computing Foundation (CNCF) Kubernetes Conformance Program. Choose a vendor that is recognized by CNFC for your hybrid cloud multicluster management.

See the following information about using CNFC providers:

* Learn how CNFC providers are certified at link:https://www.cncf.io/training/certification/software-conformance/[Certified Kubernetes Conformance].

* For Red Hat support information about CNFC third-party providers, see link:https://access.redhat.com/third-party-software-support[Red Hat support with third party components], or link:https://access.redhat.com/support/contact/[Contact Red Hat support].

* If you bring your own CNFC conformance certified cluster, you need to change the {ocp-short} CLI `oc` command to the Kubernetes CLI command, `kubectl`.

[#mce-install-new]
== Installation

Learn about new features and enhancements that come with the {mce-short} installation.

*Technology Preview:* Now when you install {mce-short}, you can enable the Kubernetes Cluster API. The `cluster-api-preview` provides capabilities to handle the Cluster API lifecycle from within a management cluster. You can also use `cluster-api-provider-aws-preview`, which provides Kubernetes-style APIs for cluster creation, configuration, and management for your Amazon Web Services (AWS) clusters. Both features are released as _Technology Preview_ and are disabled by default. You must enable the `cluster-api-preview` resource to use the `cluster-api-provider-aws-preview` resource. Learn about the Cluster API in the link:https://cluster-api.sigs.k8s.io/[Kubernetes Cluster API] documentation.

=== {mce-short} with {acm-short} integration

If you installed {acm-short} after using stand-alone {mce-short} for cluster management, you get access to all {acm-short} features. See the following new features available for {mce-short} with {acm-short} integration:

You can now configure the {acm-short} hub cluster to change the naming convention for discovered and imported hosted clusters from {mce-short} to ensure all hosted clusters are named uniquely in your entire fleet. See link:../../mce_acm_integration/discover_hosted/acm_discover_hosted.adoc#discover-hosted-acm[Discovering {mce-short} hosted clusters in {acm-short}].
