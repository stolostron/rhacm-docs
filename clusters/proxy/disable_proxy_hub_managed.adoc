[#disable-proxy-hub-managed]
= Disable the proxy between hub cluster and managed cluster

[role="_abstract"]
Disable the HTTP or HTTPS proxy between the hub cluster and the managed cluster when you no longer need the proxy.

.Procedure

. Go to the `ManagedCluster` resource.
. Remove the `agent.open-cluster-management.io/klusterlet-config` annotation.

* xref:../proxy/config_proxy_hub_managed.adoc#config-proxy-hub-managed[Configure the proxy between hub cluster and managed cluster]
