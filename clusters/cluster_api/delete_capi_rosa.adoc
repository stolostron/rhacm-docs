= Deleting a {rosa-hcp} cluster with Cluster API (Technology Preview)

Deleting the `ROSAControlPlane` deprovisions the {rosa-hcp} cluster. The process takes 30 to 50 minutes to complete. The associated `ROSAMachinePool` resources are automatically deleted.

*Required access:* Cluster administrator

.Prequisites

- You gave a {rosa-hcp} cluster with Cluster API.

.Procedure

. Delete the `ROSAControlPlane` custom resource and the matching cluster custom resource. Run the following command. Replace values where needed:

+
[source,bash]
----
oc delete -n ns-rosa-hcp cluster/rosa-hcp-1 rosacontrolplane/rosa-cp-1
----

. After the `ROSAControlPlane` deletion completes, delete the `ROSARoleConfig` and `ROSANetwork` resources.
