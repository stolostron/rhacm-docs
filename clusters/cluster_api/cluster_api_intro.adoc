= Cluster API 

Cluster API offers declarative APIs that simplify the provisioning, upgrading, and management of Kubernetes clusters. {mce-short} installs the core Cluster API components along with multiple infrastructure and bootstrap providers to support different use-cases and platforms. Learn how to use Cluster API with either standalone {mce-short} or {acm-short}. See the following processes:

* xref:../cluster_api/install_capi_managed.adoc#capi-managed-assisted[Installing a managed cluster with Cluster API]
* xref:../cluster_api/auto_import_capi.adoc#auto-import-capi[Enabling automatic import for Cluster API clusters (Technology Preview)]
* xref:../cluster_api/enable_iam_roles.adoc#enable-iam-roles-capa[Enabling IAM roles on your managed cluster with CAPA]
* xref:../cluster_api/create_capi_rosa.adoc#create-rosa-hcp-capi-cluster[Creating a {rosa-hcp} cluster with Cluster API]
* xref:../cluster_api/delete_capi_rosa.adoc#delete-rosa-hcp-capi-cluster[Deleting a {rosa-hcp} cluster with using Cluster API]
