= Cluster API 

Cluster API provides declarative APIs to simplify provisioning, upgrading, and operating multiple Kubernetes clusters. Integrate Cluster API with {mce-short} for cluster management by using a bootstrap provider, an infrastructure provider, and a control plane provider. If you installed {acm-short}, the {mce-short} is installed for Cluster API integration. Learn how to integrate Cluster API with standalone {mce-short} or {acm-short}.
