= Deleting Azure Red Hat OpenShift {hcp} clusters by using Cluster API Provider for Azure

[role="_abstract"]
Deleting an Azure Red Hat OpenShift {hcp} managed cluster deprovisions the cluster and deletes the associated resoureces. The process takes 10 to 15 minutes to complete.

*Required access:* Cluster administrator

.Prerequisites

- You have an Azure Red Hat OpenShift {hcp} managed cluster.

.Procedure

. Delete your cluster by running the following command:

+
[source,bash]
----
oc delete cluster <cluster_name> -n <cluster_namespace> 
----

.Verification

. Check if the Cluster API resources are removed. Run the following command:

+
[source,bash]
----
oc get cluster,arocontrolplane,arocluster,aromachinepool -n <cluster_namespace>
----

. Check if the Azure Service Operator resources are removed. Run the following command:

+
[source,bash]
----
oc get HcpOpenShiftCluster,HcpOpenShiftClustersNodePool -n <cluster_namespace>
----

. Check if the Microsoft Azure resources are removed. Run the following commands:

+
[source,bash]
----
 az resource list \
    --resource-group mv4-stage-resgroup \
    --output table
----

+
[source,bash]
----
az resource show \
    --resource-type Microsoft.RedHatOpenShift/HCPOpenShiftClusters \
    --name mv4-stage \
    --resource-group mv4-stage-resgroup \
    --output json | jq '.properties'
----
