= Preparing to create Azure Red Hat OpenShift {hcp} clusters by using Cluster API Provider for Azure

[role="_abstract"]
Before creating an Azure Red Hat OpenShift {hcp} managed cluster by using Cluster API Provider for Azure, you must complete the following preparation procedure.

*Required access:* Cluster administrator

.Prerequisites

- You need the `MultiClusterEngine` resource either from the {acm-short} installation, or the {mce-short} standalone installation.
- You need a valid Microsoft Azure subscription with permissions to create Azure Red Hat OpenShift {hcp} resources.
- You need the OpenShift CLI (`oc`). See link:https://docs.redhat.com/en/documentation/openshift_container_platform/4.21/html/cli_tools/openshift-cli-oc[OpenShift CLI (oc)] in the {ocp-short} documentation to learn more.
- You need the `jq` tool. See link:https://jqlang.org/[./jq] to learn more.
- You need the Azure Service Operator v2. See link:https://azure.github.io/azure-service-operator/[Azure Service Operator v2] to learn more.
- Your hub cluster must have internet access.

.Procedure

. Enable the Cluster API component. Run the following command:

+
[source,bash]
----
oc patch mce multiclusterengine --type=merge -p "{\"spec\":{\"overrides\":{\"components\":$(oc get mce multiclusterengine -o json | jq -c '.spec.overrides.components | map(if .name == "cluster-api" then .enabled = true else . end)')}}}"
----

.. Verify that the Cluster API component is enabled. Run the following command:

+
[source,bash]
----
oc get mce multiclusterengine -o json | \
  jq -r '.spec.overrides.components[] | select(.name == "cluster-api") | [.name, .enabled] | @tsv'
----

+
Make sure the output matches the following sample:

+
[source,bash]
----
cluster-api	true
----

. Enable the Cluster API Provider for Azure component. Run the following command:

+
[source,bash]
----
oc patch mce multiclusterengine --type=merge -p "{\"spec\":{\"overrides\":{\"components\":$(oc get mce multiclusterengine -o json | jq -c '.spec.overrides.components | map(if .name == "cluster-api-provider-azure-preview" then .enabled = true else . end)')}}}"
----

.. Verify that the Cluster API Provider for Azure component is enabled. Run the following command:

+
[source,bash]
----
oc get mce multiclusterengine -o json | \
  jq -r '.spec.overrides.components[] | select(.name == "cluster-api-provider-azure-preview") | [.name, .enabled] | @tsv'
----

+
Make sure the output matches the following sample:

+
[source,bash]
----
cluster-api-provider-azure-preview	true
----

. Verify that the operators are ready. Run the following command:

+
[source,bash]
----
oc get deployment -n multicluster-engine | grep -E "(capi|capz|azureserviceoperator)"
----

+
Make sure the output shows `1` in the `AVAILABLE` column for each operator. See the following example:

+
[source,bash]
----
NAME                                      READY   UP-TO-DATE   AVAILABLE   AGE
azureserviceoperator-controller-manager   1/1     1            1           2m
capz-controller-manager                   1/1     1            1           2m
capi-controller-manager                   1/1     1            1           2m
----

+
If the operators are not ready, wait until they are ready.

. Check if the `hypershift` and `hypershift-local-hosting` components are disabled. Run the following command:

+
[source,bash]
----
oc get multiclusterengine multiclusterengine -o json | \
  jq -r '.spec.overrides.components[] | [.name, .enabled] | @tsv' | \
  column -t -s $'\t' -N "COMPONENT,ENABLED"
----

+
The output might look similar to the following example:

+
[source,bash]
----
COMPONENT                                ENABLED
hypershift                               false
hypershift-local-hosting                 false
----

. If the components are enabled, disable both components.

.. Run the following command to disable the `hypershift` component:

+
[source,bash]
----
oc patch mce multiclusterengine --type=merge -p "{\"spec\":{\"overrides\":{\"components\":$(oc get mce multiclusterengine -o json | jq -c '.spec.overrides.components | map(if .name == "hypershift" then .enabled = false else . end)')}}}"
----

.. Run the following command to disable the `hypershift-local-hosting` component:

+
[source,bash]
----
oc patch mce multiclusterengine --type=merge -p "{\"spec\":{\"overrides\":{\"components\":$(oc get mce multiclusterengine -o json | jq -c '.spec.overrides.components | map(if .name == "hypershift-local-hosting" then .enabled = false else . end)')}}}"
----

. Verify that the components are disabled. Run the following command:

+
[source,bash]
----
oc get deployment -n hypershift
----

+
Make sure the output matches the following sample:

+
----
No resources found in hypershift namespace.
----

. Configure your Microsoft Azure credentials.

.. Create a service principal with permissions to manage Azure Red Hat OpenShift {hcp} resources. Run the following command. Replace `<subscription_id>` with your subscription ID:

+
[source,bash]
----
az ad sp create-for-rbac \
  --name "aro-hcp-capz-sp" \
  --role "Contributor" \
  --scopes "/subscriptions/<subscription_id>"
----

+
Save the following information from the output for the next step:

+
- `tenant`
- `appId`
- `password`

.. Create a `Secret resource with your Microsoft Azure credentials for Azure Service Operator. Use the following YAML sample:

+
[source,yaml]
----
apiVersion: v1
kind: Secret
metadata:
  name: aso-credential
  namespace: default
stringData:
  AZURE_SUBSCRIPTION_ID: "<subscription_id>"
  AZURE_TENANT_ID: "<tenant_id>"
  AZURE_CLIENT_ID: "<client_id>"
  AZURE_CLIENT_SECRET: "<client_secret>"
----

+
- Replace <subscription_id> with your subscription ID.
- Replace <tenant_id> with the `tenant` value from the previous step.
- Replace <client_id> with the `appId` value from the previous step.
- Replace <client_secret> with the `password` value from the previous step.

.. Apply the YAML file. Run the following command:

+
[source,bash]
----
oc apply -f
----

.Additional resources

- To learn more about Azure Red Hat OpenShift, see the link:https://learn.microsoft.com/en-us/azure/openshift/[Azure Red Hat OpenShift documentation].
