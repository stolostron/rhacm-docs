= Discover APIs from the command line

[role="_abstract"]
You can view {mce-short} custom resources definitions from the command line by using the Kubernetes CLI (`kubectl`). List available APIs and inspect CRD details on your managed clusters.

*Required access:* Cluster administrator, or a role with permission to list and get custom resources definitions

.Prerequisites

* You installed a supported version of {ocp-short} on your hub cluster. See link:https://docs.redhat.com/en/documentation/openshift_container_platform/4.20/html/installation_overview/index[Installing {ocp-short}].

* {mce-short} is installed on the hub cluster. If you installed {acm-short}, {mce-short} is installed automatically. See link:../get_started_mce/prepare_install_mce_connected.adoc#preparing-to-install-mce[Preparing to install {mce-short}].

* You configured the {ocp-short} CLI (`oc`) or the Kubernetes CLI (`kubectl`) on your workstation and can run commands against the hub cluster. See link:https://docs.redhat.com/en/documentation/openshift_container_platform/4.20/html/cli_tools/openshift-cli-oc#cli-getting-started[Getting started with the OpenShift CLI].

* You are logged in to the hub cluster with credentials that can access API resources.

.Procedure

. List the APIs that are available on the cluster:

+
[source,bash]
----
kubectl get crds
----

. To view details for a specific API, run the following command. Replace `<name>` with the CRD name from the previous step:

+
[source,bash]
----
kubectl describe crd <name>
----
