[#install-search-mcp]
= Installing the Search MCP server

[role="_abstract"]
Install the Search MCP server from the published Helm repository on your {acm-short} hub cluster. The Helm chart automatically discovers your {acm-short} `MultiClusterHub` installation, extracts database credentials, and deploys the MCP server with the required configuration.

*Required access:* Cluster administrator

.Prerequisites

* An {ocp-short} cluster with {acm-short} installed
* Helm 3.x installed locally
* `oc` or `kubectl` access to the cluster

.Procedure

. Add the Search MCP Helm repository:

+
[source,bash]
----
helm repo add acm-search https://stolostron.github.io/search-mcp-server
helm repo update
----

. Install the Search MCP server with auto-discovery:

+
[source,bash]
----
helm install acm-mcp-server acm-search/acm-mcp-server \
  --create-namespace \
  --namespace acm-search
----

+
The Helm chart automatically completes the following tasks:

* Discovers your {acm-short} `MultiClusterHub` installation
* Extracts database credentials from {acm-short}
* Builds the complete database connection URL
* Deploys the MCP server with the required configuration

. Verify that the MCP server is running in the `acm-search` namespace:

+
[source,bash]
----
oc get pods -n acm-search
----

+
After you install the Search MCP server, enable it with an MCP client. See xref:../search/enable_search_mcp_lightspeed.adoc#enable-search-mcp-lightspeed[Enabling the Search MCP server with OpenShift Lightspeed] or xref:../search/enable_search_mcp_claude.adoc#enable-search-mcp-claude[Enabling the Search MCP server with Claude Code].
