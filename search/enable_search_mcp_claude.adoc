[#enable-search-mcp-claude]
= Enabling the Search MCP server with Claude Code

[role="_abstract"]
Configure Claude Code to connect to the search {mcp-short} on your {acm-short} hub cluster.

You must run Claude Code on the {acm-short} hub cluster where the search {mcp-short} is installed.

*Required access:* Cluster administrator

.Prerequisites

* The search {mcp-short} is installed on your {acm-short} hub cluster. See xref:../search/install_search_mcp.adoc#install-search-mcp[Installing the search {mcp-short}].
* Claude Code is installed on the machine where you run this procedure.

.Procedure

. Log in to the {acm-short} hub cluster by using the `oc` command.

. Set the `NODE_TLS_REJECT_UNAUTHORIZED` environment variable to `0` in your command-line environment:

+
[source,bash]
----
export NODE_TLS_REJECT_UNAUTHORIZED=0
----

. Retrieve the route that was created by the search {mcp-short} installation in the `acm-search` namespace:

+
[source,bash]
----
export ROUTE=$(oc get route acm-mcp-server -n acm-search -o jsonpath='{.spec.host}')
----

. Add the search {mcp-short} to Claude Code:

+
[source,bash]
----
claude mcp add --transport http -s project acm-search https://${ROUTE}/mcp --header "Authorization: Bearer $(oc whoami -t)"
----

. Log in to Claude Code, connect to the {mcp-short} named `acm-search`, and start using the search {mcp-short} tools.
