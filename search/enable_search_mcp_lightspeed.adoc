[#enable-search-mcp-lightspeed]
= Enabling the {mcp-short} with {lightspeed-short}

[role="_abstract"]
Configure {lightspeed-short} to use the {mcp-short} so that you can query {acm-short} search data from the Lightspeed assistant.

*Required access:* Cluster administrator

.Prerequisites

* The {mcp-short} is installed on your {acm-short} hub cluster. See xref:../search/install_search_mcp.adoc#install-search-mcp[Installing the {mcp-short}].
* {lightspeed-short} is installed and configured on the {acm-short} hub cluster where you want to add the {mcp-short}. For more information, see link:https://docs.redhat.com/en/documentation/red_hat_openshift_lightspeed/1.0/html/install/index[Red Hat OpenShift Lightspeed] installation documentation.

.Procedure

. Update your `OLSConfig` custom resource to add the {mcp-short}.

+
If you do not have MCP servers configured in your `OLSConfig` custom resource, add the following configuration:

+
[source,yaml]
----
mcpServers:
  - headers:
      - name: Authorization
        valueFrom:
          type: kubernetes
    name: acm
    timeout: 30
    url: 'http://acm-mcp-server.acm-search.svc.cluster.local/mcp'
----

+
If your `OLSConfig` custom resource already has MCP servers configured, add the {mcp-short} to the existing `mcpServers` list. Your configuration might resemble the following example:

+
[source,yaml]
----
mcpServers:
  - name: existing-server
    # ... existing server config ...
  - name: acm
    streamableHTTP:
      enableSSE: false
      headers:
        kubernetes-authorization: kubernetes
      sseReadTimeout: 10
      timeout: 30
      url: 'http://acm-mcp-server.acm-search.svc.cluster.local/mcp'
----

*Notes:*

* If you already have MCP servers configured in your `OLSConfig` custom resource, add the {mcp-short} to the existing list rather than replacing it.
* Use the exact configuration shown in this topic for proper functionality.
* The service URL assumes that the {mcp-short} is deployed in the `acm-search` namespace, which is the default namespace for the Helm chart.
