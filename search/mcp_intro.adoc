= Model Context Protocol server (Technology Preview)

[role="_abstract"]
The Model Context Protocol (MCP) server provides  standardized interface to access {acm} search database and Kubernetes resources across managed clusters. This implementation enables Large Language Models (LLMs) to retrieve real-time infrastructure data and state information through a consistent protocol.

Use the `find_resources` tool to enable advanced searching of Kubernetes resources across all managed clusters. The `find_resources` tool uses the {acm-short} search index to provide comprehensive filtering and output customization. 

.Table of filter parameters
|===
| Category | Parameters  

| Basic filters
| `kind`, `name`, `namespace`, `cluster`, `status`

| Advanced filters
| `labelSelector`, `clusterSelector`, `textSearch`, `ageNewerThan`, `ageOlderThan`

| Output control filter
| `outputMode`, `list`, `count`, `summary`, `health`, `groupBy`, `sortBy`, `sortOrder`, `limit`, `countOnly`
