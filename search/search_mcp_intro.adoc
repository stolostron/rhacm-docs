= Search MCP server overview

[role="_abstract"]
The Search MCP server is a Model Context Protocol (MCP) server that provides access to the {acm-short} Search database and Kubernetes resources across managed clusters.

Use the Search MCP server to query cluster resources from AI assistants and other MCP clients. The server exposes tools that search the same data that powers the {acm-short} Search service.

== Available tools

The Search MCP server provides the `find_resources` tool for advanced Kubernetes resource search across all managed clusters.

You can use the following filters with `find_resources`:

*Basic filters:*

* `kind`
* `name`
* `namespace`
* `cluster`
* `status`

*Advanced filters:*

* `labelSelector`
* `clusterSelector`
* `textSearch`
* `ageNewerThan`
* `ageOlderThan`

*Output control:*

* `outputMode` (`list`, `count`, `summary`, or `health`)
* `groupBy`
* `sortBy`
* `sortOrder`
* `limit`
* `countOnly`
