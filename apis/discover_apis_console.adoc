= Discover APIs from the console

[role="_abstract"]
You can view {acm-short} custom resources definitions in the integrated console. List available APIs and display API details for your hub cluster and managed clusters.

*Required access:* Cluster administrator, or a role with permission to list and get custom resources definitions

.Prerequisites

* You installed a supported version of {ocp-short} on your hub cluster. See link:https://docs.redhat.com/en/documentation/openshift_container_platform/4.19/html/installation_overview/index[Installing {ocp-short}].

* You installed {acm-short} on the hub cluster. See link:../install/preparing_acm_install.adoc#prepare-install-acm[Preparing for {acm-short} installation].

* {mce-short} is installed on the hub cluster. If you installed {acm-short}, {mce-short} is installed automatically. See link:../clusters/get_started_mce/prepare_install_mce_connected.adoc#preparing-to-install-mce[Preparing to install {mce-short}].

* You configured the {ocp-short} CLI (`oc`) or the Kubernetes CLI (`kubectl`) on your workstation and can run commands against the hub cluster. See link:https://docs.redhat.com/en/documentation/openshift_container_platform/4.19/html/cli_tools/openshift-cli-oc#cli-getting-started[Getting started with the OpenShift CLI].

* You are logged in to the hub cluster with credentials that can access API resources.

.Procedure

. In the {ocp-short} console, choose the *Core platform* view.

. Click *Home* > *API Explorer* in the navigation menu.

. From the *API Explorer* page, sort by groups, versions, scope, and kind to view the available APIs and _Resource details_ for your hub cluster and managed clusters. You can also change the amount of information that is displayed by selecting the number `per page` from the drop-down menu.
