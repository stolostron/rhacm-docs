[#search-api]
= Search API

The search service provides a GraphQL API endpoint that allows applications to query for indexed resources.

== Overview

Use the Search API to query resources that match filters or keywords, and to watch for resource changes across your managed clusters. This document explains how to access the GraphQL endpoint and enable the schema documentation.

== Configure API access

Create a route to access the Search API external from your cluster with the following command:

[source,bash]
----
oc create route passthrough search-api --service=search-search-api -n open-cluster-management
----

*Important:* You must configure your route to secure your environment. See link:https://docs.redhat.com/en/documentation/openshift_container_platform/4.20/html-single/ingress_and_load_balancing/index#configuring-routes[Configuring Routes] in the {ocp-short} documentation for more details.

== Enable API documentation

Before you can access the Search API documentation, you must enable the `API_DOCUMENTATION` environment variable on the `search-api` deployment by setting `API_DOCUMENTATION='true'`. The `search-v2-operator` custom resource defines the `search-api` deployment configuration. Run the following command to update it:

[source,bash]
----
oc patch search -n open-cluster-management search-v2-operator --type json -p '[{"op": "add", "path": "/spec/deployments/queryapi/envVar", "value": [{"name": "API_DOCUMENTATION", "value": "true"}]}]'
----


== Query examples

[source,json]
----
{
  "query": "type SearchResult {count: Intitems: [Map]related: [SearchRelatedResult]} type SearchRelatedResult {kind: String!count: Intitems: [Map]}",
  "variables": {
    "input": [
      {
        "keywords": [],
        "filters": [
          {
            "property": "kind",
            "values": [
              "Deployment"
            ]
          }
        ],
        "limit": 10,
        "offset": 5,
        "orderBy": "name asc"
      }
    ]
  }
}
----


== Supported queries

Continue reading to see the query types that are supported in JSON format.

== Search for deployments

Query:

[source,graphql]
----
query mySearch($input: [SearchInput]) {
    search(input: $input) {
    		items
        }
}
----

Variables:

[source,graphql]
----
{"input":[
    {
        "keywords":[],
        "filters":[
            {"property":"kind","values":["Deployment"]}],
        "limit":10
    }
]}
----
