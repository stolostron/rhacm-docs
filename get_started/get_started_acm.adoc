[#get-started-acm]
= Get started with {acm-short}

[role="_abstract"]
Install {acm-short} through {olm}, which manages the installation, update, and removal of the components that encompass the {acm-short} hub cluster. You can also find information about updating, uninstalling, and cleaning up artifacts before reinstalling. See advanced configuration information for {acm-short} and discover APIs from the console or command line. After you create the `MultiClusterHub` resource during installation, the {acm-short} operator automatically installs the {mce-short}  and creates the `MultiClusterEngine` resource. 

You must have a supported version of {ocp-short} to install {acm-short}. Review the required hardware and system configuration for each product. You can install online on Linux with a supported version of {ocp-short}. 

For full support information, see the link:https://access.redhat.com/articles/7142376[{acm-short} Support Matrix] and the link:https://access.redhat.com/support/policy/updates/advanced-cluster-management[Lifecycle and update policies for {acm}].

*Deprecated:* {acm-short} 2.12 and earlier versions are no longer supported. The documentation might remain available, but without any errata releases for fixed issues or other updates. For lifecycle information, see link:https://access.redhat.com/support/policy/updates/openshift[{ocp} Life Cycle policy] and link:https://access.redhat.com/support/policy/updates/openshift_operators#platform-aligned[Platform-aligned operators].
