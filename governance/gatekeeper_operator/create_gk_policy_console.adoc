= Creating a Gatekeeper policy from the console

[role="_abstract"]
Create a Gatekeeper policy from the console and set remediation to `enforce` to install Gatekeeper.

*Required access*: Cluster administrator

.Procedure

. Log in to the {acm-short} console.

. Navigate to the _Governance_ page and create a Gatekeeper policy.

. Set remediation to `enforce` to install Gatekeeper.
