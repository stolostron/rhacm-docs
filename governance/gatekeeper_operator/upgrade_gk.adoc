= Upgrading Gatekeeper and the {gate}

[role="_abstract"]
Upgrade Gatekeeper and the {gate} on managed clusters by using the `upgradeApproval` setting in the {gate} policy.

*Required access*: Cluster administrator

. Upgrade {gate} automatically by setting `upgradeApproval` to `Automatic`. 

. Approve {gate} upgrades manually by setting `upgradeApproval` to `Manual`. 

+
*Note:* You must manually approve the upgrade for each cluster where the {gate} is installed.
