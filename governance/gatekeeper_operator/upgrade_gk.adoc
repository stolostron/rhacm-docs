= Upgrading Gatekeeper and the {gate}

[role="_abstract"]
Upgrade Gatekeeper and the {gate} on managed clusters by using the `upgradeApproval` setting in the {gate} policy.

*Required access*: Cluster administrator

When you install the {gate} with the {gate} policy, notice the value for `upgradeApproval`. The operator upgrades automatically when you set `upgradeApproval` to `Automatic`.

If you set `upgradeApproval` to `Manual`, you must manually approve the upgrade for each cluster where the {gate} is installed.
