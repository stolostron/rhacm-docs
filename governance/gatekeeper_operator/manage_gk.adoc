= Manage the {gate} installation policies

[role="_abstract"]
Use the {acm-short} policy to install the {gate} and Gatekeeper on a managed cluster.

*Required access*: Cluster administrator

.Procedure

. Install Gatekeeper by using a {gate} policy. Use the configuration policy controller. 

+
*Note:* During the install, the operator group and subscription pull the {gate} to install it on your managed cluster. Then, the policy creates a Gatekeeper custom resource to configure Gatekeeper.

. Set the remediation action to `enforce` on the {gate} policy. 

+
*Note:* The {acm-short} configuration policy controller supports the `enforce` remediation action and automatically creates the {gate} objects on the managed cluster.
