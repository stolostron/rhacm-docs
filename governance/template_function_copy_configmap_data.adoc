[#copy-configmap-data]
= copyConfigMapData

[role="_abstract"]
The `copyConfigMapData` function copies all of the `data` content of the specified config map.

View the following sample of the function:

[source,yaml]
----
...
objectDefinition:
  apiVersion: v1
  kind: ConfigMap
  metadata:
    name: my-secret-copy
  data: '{{ copyConfigMapData "default" "my-configmap" }}'
----
