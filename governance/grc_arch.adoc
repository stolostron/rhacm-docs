= Governance policy framework architecture

[role="_abstract"]
Enhance cluster security with the {acm} governance lifecycle. The governance lifecycle uses supported policies, processes, and procedures to manage security and compliance from a central interface.

The following diagram shows the governance architecture:

image:../images/governance_arch_2.8.png[Governance architecture diagram]

* Governance architecture components:

** *Governance dashboard:* Provides a summary of your cloud governance and risk details, which include policy and cluster violations. See _Governance dashboard_ to learn about the structure of an {acm} policy framework and how to use the {acm} _Governance_ dashboard.

** *Policy-based governance framework:* Supports policy creation and deployment to various managed clusters based on attributes associated with clusters, such as a geographical region. Predefined policy examples and deployment instructions are available in the _policy-collection_ repository. When a policy becomes noncompliant, you can configure policy violation automation to run an action of your choice.

** *Open source community:* Supports community contributions with a foundation of the {acm-short} policy framework. Policy controllers and third-party policies are also part of the `open-cluster-management-io` project. You can contribute and deploy policies by using GitOps.
