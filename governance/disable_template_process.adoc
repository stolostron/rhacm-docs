[#disable-template-processing]
= Disabling template processing in policies

[role="_abstract"]
By default, the governance framework processes all Go templates within configuration definitions. For `policy-templates` you do not want to process, disable individual templates.


.Procedure

. To disable template processing for a particular template, add the `pass:` label in the raw string. The template returns a raw string to be processed by a subsequent templating engine. See the following example where `{{ template content }}` is ignored:

+
----
{{ pass:[`{{ template content }}`] }}
----

. To completely disable the template resolution for a configuration policy, set the `disable-templates` parameter to `"true"` in the relevant `ConfigurationPolicy` resource. Your YAML file might resemble the following resource:

+
[source,yaml]
----
apiVersion: policy.open-cluster-management-observability.io/v1
kind: ConfigurationPolicy
metadata:
  name: sample-policy
  annotations:
    policy.open-cluster-management.io/disable-templates: "true"
----
