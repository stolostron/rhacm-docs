= New features and enhancements for the {mce-short}

[role="_abstract"]
Learn about {mce} 5.0 new features and enhancements, support, deprecations, removals, and fixed issues for errata releases. {mce-short} version 5.0 is released with {acm-short} version 5.0 for Cluster lifecycle management, but you can use stand-alone {mce-short} with your {ocp-short} hub cluster, as well.

For full support information, including supported {ocp-short} versions, see the link:https://access.redhat.com/articles/7149097[{mce-short} Support Matrix]. For lifecycle information, see link:https://access.redhat.com/support/policy/updates/openshift[{ocp} Life Cycle policy].

Use {mce-short} features for creating, importing, managing, and destroying Kubernetes clusters across various infrastructure cloud providers, private clouds, and on-premises data centers.

If you are using {mce-short} with {acm-short} installed afterwards, see the link:../release_notes/acm_new.adoc#new-features-acm[New features and enhancements for {acm-short}] this release.

*Important:* 

- Cluster management supports all providers that are certified through the Cloud Native Computing Foundation (CNCF) Kubernetes Conformance Program. Choose a vendor that is recognized by CNCF for your hybrid cloud multicluster management. See the following information about using CNCF providers:

- Learn how CNCF providers are certified at link:https://www.cncf.io/training/certification/software-conformance/[Certified Kubernetes Conformance].

- For Red Hat support information about CNCF third-party providers, see link:https://access.redhat.com/articles/third-party-software-support[Red Hat support with third party components], or link:https://access.redhat.com/support/contact/[Contact Red Hat support].

- If you bring your own CNCF conformance certified cluster, you need to change the {ocp-short} CLI `oc` command to the Kubernetes CLI command, `kubectl`.

- Some features and components are identified and released as link:https://access.redhat.com/support/offerings/techpreview[Technology Preview].

- New features and enhancements for {mce-short} 5.0 include the following changes:

* You can now add rich-text descriptions to the cluster details page to help with managing large fleets. Use the _Description_ field to annotate clusters with Markdown-formatted text and clickable links to per-cluster tools, such as monitoring dashboards, logging endpoints, and runbooks, which are displayed on the cluster overview page.

* You can navigate more easily between clusters with usability improvements on the hub cluster and managed cluster consoles. The managed cluster list contains a link to each managed cluster console, and the console for each managed cluster contains a link to the hub cluster.
