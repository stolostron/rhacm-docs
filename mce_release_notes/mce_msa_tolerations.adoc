= Set tolerations and nodeSelector for managed-serviceaccount agent

[role="_abstract"]
Set the `tolerations` and `nodeSelector` parameters in the `MultiClusterEngine` and `MultiClusterHub` resources for the `managed-serviceaccount` agent deployed on the local cluster. 

The `managed-serviceaccount` add-on is not always required on the local cluster. If the `managed-serviceaccount` add-on is required, you can work around the issue by completing the following steps.

To learn more about how to use the `addonDeploymentConfig` custom resource to configure `tolerations` and `nodeSelector` for add-on, see link:../add-ons/configure_addon_deployment_config.adoc#setting-addondeploymentconfig-klusterlet-addons[Set up the _AddOnDeploymentConfig_ to configure klusterlet add-ons].

.Procedure

. Create the `addonDeploymentConfig` custom resource.

. Set the `tolerations` and `nodeSelector` values for the local cluster and `managed-serviceaccount` agent.

. Update the `managed-serviceaccount` `ManagedClusterAddon` in the local cluster namespace to use the `addonDeploymentConfig` custom resource you created.
