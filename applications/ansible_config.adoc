[#ansible_config]
= Configure {aap-short}

[role="_abstract"]
With {aap-short} jobs, you can automate tasks and integrate with external services, such as Slack and PagerDuty services. Your Git repository resource root path will contain `prehook` and `posthook` directories for {aap-short} jobs that run as part of deploying the application, updating the application, or removing the application from a cluster.

*Required access:* Cluster administrator

*Deprecation:* Application _subscription_, and all processes that use Application subscription, is deprecated. See link:../gitops/gitops_overview.adoc#gitops-overview[GitOps overview] for updated function.

You can configure {aap-short} configurations with the following tasks:

* xref:../applications/ansible_secrets.adoc#ansible-secrets[Set up {aap-short} secrets]
* xref:../applications/ansible_secret_reconciliation.adoc#ansible-secret-reconciliation[Set secret reconciliation]
* xref:../applications/ansible_sample_yaml.adoc#ansible-sample-yaml[Use {aap-short} sample YAML files]
* xref:../applications/ansible_launch_workflow.adoc#launch-workflow[Launch Workflow]
* xref:../applications/ansible_workflow_sample.adoc#workflow-sample-yaml[Use {aap-short} sample YAML Workflow]
