[#managing-application-resources]
= Manage application resources

[role="_abstract"]
From the console, you can create applications by using Git repositories, Helm repositories, and Object storage repositories.

*Deprecation:* Application _subscription_, and all processes that use Application subscription, is deprecated. See link:../gitops/gitops_overview.adoc#gitops-overview[GitOps overview] for updated function.

**Important:** Git Channels can share a namespace with all other channel types: Helm, Object storage, and other Git namespaces.

To configure a proxy server while managing applications, see link:../add-ons/cluster_wide_proxy.adoc#enable-cluster-wide-proxy-addon[Enabling cluster-wide proxy on existing cluster add-ons].
