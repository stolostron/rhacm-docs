[#sample-yaml-object]
= Sample YAML

[role="_abstract"]
The following example channel definition abstracts an object storage as a channel:

[source,yaml]
----
apiVersion: apps.open-cluster-management.io/v1
kind: Channel
metadata:
 name: dev
 namespace: ch-obj
spec:
 type: Object storage
 pathname: [http://sample-ip:#####/dev] # URL is appended with the valid bucket name, which matches the channel name.
 secretRef:
   name: <s3-secret>
 gates:
   annotations:
     dev-ready: true
----

*Note:* To view REST APIs, use the _API Explorer_ in the console, or an `oc` command.
