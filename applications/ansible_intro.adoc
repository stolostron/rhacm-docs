[#aap-intro]
= {aap-short} integration

[role="_abstract"]
{acm-short} is integrated with {aap} so that you can create prehook and posthook `AnsibleJob` instances for Git subscription application management. Learn about the components and how to configure {aap-short}.

*Required access:* Cluster administrator

*Deprecation:* Application _subscription_, and all processes that use Application subscription, is deprecated. See link:../gitops/gitops_overview.adoc#gitops-overview[GitOps overview] for updated function.
