[#creating-insecure-http-object-server]
= Creating an insecure HTTPS connection to an object storage server

[role="_abstract"]
In your _development_ environment, use a connection method to connect a privately hosted object storage server with the TLS certificates that are signed by the custom certificate authority (CA) certificates. By doing this, you create an insecure HTTPS connection to an object storage server. 

To create an insecure HTTPS connection to an object storage server, complete the following steps:

.Procedure

. In the channel specification, specify `insecureSkipVerify: true`. 
. Use the following YAML as your connection method:

+
[source,yaml]
----
apiVersion: apps.open-cluster-management.io/v1
kind: Channel
metadata:
labels:
  name: sample-channel
  namespace: sample
spec:
  type: ObjectBucket
  pathname: <ObjectBucket HTTPS URL>
  insecureSkipVerify: true
----
