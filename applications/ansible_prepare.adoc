= Prepare to set up {aap-short}

[role="_abstract"]
Complete the following steps before you integrate {aap-short} with Git subscriptions.

.Procedure

. Install a supported {ocp-short} version.
. Install {aap-short}. See link:https://docs.redhat.com/en/documentation/red_hat_ansible_automation_platform[Red Hat Ansible Automation Platform] documentation to install the latest supported version.
. Install the {aap-short} Resource Operator to connect {aap-short} jobs to the lifecycle of Git subscriptions. Make sure the {aap-short} job template is idempotent.
+
You can install the {aap-short} Resource Operator on a different cluster than the hub cluster. If you install the {aap-short} Resource Operator on the hub cluster, the operator must be the same version as the {aap-short} Tower.
. Check `PROMPT ON LAUNCH` on the template for both `INVENTORY` and `EXTRA VARIABLES`. See link:https://docs.ansible.com/ansible-tower/latest/html/userguide/job_templates.html[Job templates] for more information.
