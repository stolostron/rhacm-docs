[#update-channel-secret-config]
= Update certificates and SSH keys

[role="_abstract"]
You can update CA certificates, credentials, or SSH keys for a Git channel connection.

.Procedure

* Create a new secret and `ConfigMap` in the same namespace and update the channel to reference that new secret and `ConfigMap`. For more information, see xref:../applications/git_channel_ca_certs.adoc#using-custom-CA-certificates-for-secure-HTTPS-connection[Use custom CA certificates for a secure HTTPS connection].
