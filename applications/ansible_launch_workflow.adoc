[#launch-workflow]
= Launching Workflow

[role="_abstract"]
To launch an {aap-short} Workflow by using the `AnsibleJob` custom resource, replace the `job_template_name` field with the `workflow_template_name`.

.Procedure

* Replace the `job_template_name` field with the `workflow_template_name`. See xref:../applications/ansible_workflow_sample.adoc#workflow-sample-yaml[Using {aap-short} sample YAML Workflow].
