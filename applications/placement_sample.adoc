= Placement rule samples overview (Deprecated)

[role="_abstract"]
*Deprecated:* `PlacementRules` is deprecated. Use `Placement` instead.

*Deprecation:* Application _subscription_, and all processes that use Application subscription, is deprecated. See link:../gitops/gitops_overview.adoc#gitops-overview[GitOps overview] for updated function.

Placement rules (`placementrule.apps.open-cluster-management.io`) define the target clusters where deployables can be deployed. Use placement rules to help you facilitate the multicluster deployment of your deployables.

To use the OpenShift CLI tool, see xref:../applications/app_apply_yaml_cli.adoc#app-apply-yaml-cli[Apply application YAML files with the CLI].
