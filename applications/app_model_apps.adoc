[#applications]
= Applications

[role="_abstract"]
Applications (`application.app.k8s.io`) in {acm} are used for grouping Kubernetes resources that make up an application.

All of the application component resources for {acm} applications are defined in YAML file specification sections. When you need to create or update an application component resource, you need to create or edit the appropriate section to include the labels for defining your resource. 

You can also work with _Discovered_ applications, which are applications that are discovered by the {ocp-short} GitOps or an Argo CD operator that is installed in your clusters. Applications that share the same repository are grouped together in this view.
