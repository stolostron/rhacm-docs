[#application-file-samples]
= Application file samples

[role="_abstract"]
For application samples that you can deploy, see the link:https://github.com/stolostron/application-samples[`stolostron`] repository.

The definition structure for an application can resemble the following example YAML content:

[source,yaml]
----
apiVersion: app.k8s.io/v1beta1
kind: Application
metadata:
  name: my-application
  namespace: my-namespace
spec:
  selector:
    matchLabels:
      my-label: my-label-value
----
