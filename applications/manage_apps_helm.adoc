= Manage apps with Helm repositories

[role="_abstract"]
When you deploy Kubernetes resources using an application, the resources are located in specific repositories. Learn how to deploy resources from Helm repositories in the following procedure. Learn more about the application model at _Application model and definitions (Deprecated)_.

Helm provides an annotation to keep specific deployed resources after you delete a subscription. *Note:* The annotation must be in the Helm chart.

*Deprecation:* Application _subscription_, and all processes that use Application subscription, is deprecated. See _GitOps overview_ for updated function.

*User required access:* A user role that can create applications. You can only perform actions that your role is assigned. Learn about access requirements from the _Role-based access control_ documentation.

.Procedure

. From the console navigation menu, click *Applications* to see listed applications and to create new applications.
. *Optional:* After you choose the kind of application you want to create, you can select *YAML: On* to view the YAML in the console as you create and edit your application. See the YAML samples later in the topic.
. Choose *Helm* from the list of repositories that you can use and enter the values in the correct fields. Follow the guidance in the console and see the YAML editor change values based on your input.
. Click *Create*.
. You are redirected to the _Overview_ page where you can view the details and topology.
