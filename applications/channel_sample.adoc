= Channel samples overview

[role="_abstract"]
View samples and YAML definitions that you can use to build your files. Channels (`channel.apps.open-cluster-management.io`) provide you with improved continuous integration and continuous delivery capabilities for creating and managing your {acm} applications.

*Deprecation:* Application _subscription_, and all processes that use Application subscription, is deprecated. See link:../gitops/gitops_overview.adoc#gitops-overview[GitOps overview] for updated function.

To use the OpenShift CLI tool, see xref:../applications/app_apply_yaml_cli.adoc#app-apply-yaml-cli[Applying application YAML files with the CLI].
