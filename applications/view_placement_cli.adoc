[#view-placement-cli]
= Viewing placement rule status with the CLI

[role="_abstract"]
You can view placement rule status by using the OpenShift CLI.

.Procedure

. Run the following command. Replace `name` and `namespace` with the name of the placement rule and the target namespace:
+
[source,bash]
----
oc get PlacementRule <name> -n <namespace>
----
. Review the fields and values within the `status` section of the YAML content.
