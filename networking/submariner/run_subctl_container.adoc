[#run-subctl-in-container]
= Running subctl in a container

[role="_abstract"]
You can run `subctl` directly from the container image.

.Procedure

. Run `subctl` from the container image by using a command that resembles the following example. Replace `<version>` with the version tag that matches your Submariner deployment, for example `v0.22`. Replace `<subcommand>` with any `subctl` command, for example `show all` or `diagnose all`:

+
[source,bash]
----
podman run --rm -v ~/.kube:/.kube:z -e KUBECONFIG=/.kube/config \
  registry.redhat.io/rhacm2/subctl-rhel9:<version> <subcommand>
----
