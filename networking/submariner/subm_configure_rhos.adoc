= Configuring Submariner for a {ocp} network

[role="_abstract"]
If you installed your cluster into an {ocp-short} network, add the `subnet-names` to the `annotations` field of the `SubmarinerConfig` resource. Add the subnet names as a comma-separated list. This configuration allows Submariner to discover the subnets in your {ocp-short} network.

*Required access:* Cluster administrator

.Procedure

Complete the following steps to configure Submariner for an {ocp-short} network:

. Open the `SubmarinerConfig` resource for editing. Run the following command, replacing values where needed:

+
[source,bash]
----
oc edit submarinerconfig -n <managed-cluster-ns> submariner
----

. Add the `subnet-names` for the {ocp-short} network to the `annotations` field. Your `SubmarinerConfig` resource might resemble the following example:

+
[source,yaml]
----
annotations:
  submariner.io/subnet-names: subnet-name1,subnet-name2, subnet-name3
----
