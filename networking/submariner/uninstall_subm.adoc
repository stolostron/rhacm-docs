= Uninstalling Submariner

[role="_abstract"]
You can uninstall the Submariner components from your clusters using the {acm} console or the command-line. For Submariner versions earlier than 0.12, additional steps are needed to completely remove all data plane components. The Submariner uninstall is idempotent, so you can repeat steps without any issues.

See the following topics to uninstall Submariner:

* xref:../submariner/uninstall_subm_console.adoc#uninstalling-submariner-console[Uninstalling Submariner by using the console]
* xref:../submariner/uninstall_subm_cli.adoc#uninstalling-submariner-cli[Uninstalling Submariner by using the CLI]
* xref:../submariner/uninstall_subm_manual.adoc#uninstalling-submariner-manually[Uninstalling Submariner manually]
