= Verifying Submariner resource removal

[role="_abstract"]
After uninstalling Submariner, verify that all of the Submariner resources are removed from your clusters. If they remain on your clusters, some resources continue to collect charges from infrastructure providers.

Ensure that you have no additional Submariner resources on your cluster by completing the following steps:

.Procedure

. Run the following command to list any Submariner resources that remain on the cluster. Replace `CLUSTER_NAME` with the name of your cluster:

+
[source,bash]
----
oc get cluster <CLUSTER_NAME> grep submariner
----

. Remove any resources on the list by entering the following command. Replace `RESOURCE_NAME` with the name of the Submariner resource that you want to remove and `CLUSTER_NAME` with the name of your cluster:
+
[source,bash]
----
oc delete resource <RESOURCE_NAME> cluster <CLUSTER_NAME>
---- 

. Repeat steps 1-2 for each of the clusters until your search does not identify any resources.
