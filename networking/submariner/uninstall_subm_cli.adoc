= Uninstalling Submariner by using the CLI

[role="_abstract"]
To uninstall Submariner by using the command line, complete the following steps:

.Procedure

. Remove the Submariner deployment for the cluster by running the following command. Replace `managed-cluster-namespace` with the namespace of your managed cluster:
+
[source,bash]
----
oc -n <managed-cluster-namespace> delete managedclusteraddon submariner
----

. Remove the cloud resources of the cluster by running the following command. Replace `managed-cluster-namespace` with the namespace of your managed cluster:
+
[source,bash]
----
oc -n <managed-cluster-namespace> delete submarinerconfig submariner
----

. Delete the cluster set to remove the broker details by running the following command. Replace `managedclusterset` with the name of your managed cluster set:
+
[source,bash]
----
oc delete managedclusterset <managedclusterset>
----

. Verify that all of the cloud resources are removed from the cloud provider to avoid additional charges by your cloud provider. See xref:../submariner/verify_subm_resource_removal.adoc#verifying-subm-resource-removal[Verifying Submariner resource removal] for more information.
