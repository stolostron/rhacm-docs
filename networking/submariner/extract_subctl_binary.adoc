[#extract-subctl-binary]
= Extracting the subctl binary

[role="_abstract"]
If you prefer a local binary, you can extract `subctl` from the container image. The extracted binary requires Red Hat Enterprise Linux 9 or later.

.Procedure

. Extract `subctl` from the container image by running the following command. Replace `<version>` with the version tag that matches your Submariner deployment, for example `v0.22`:

+
[source,bash]
----
podman cp "$(podman create registry.redhat.io/rhacm2/subctl-rhel9:<version>):/usr/local/bin/subctl" subctl
----
+
*Notes:*
* Make sure that the `subctl` and Submariner versions match.
* For disconnected environments only, make sure to mirror the `submariner-nettest` image.
