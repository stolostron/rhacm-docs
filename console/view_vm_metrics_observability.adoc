= Viewing virtual machine metrics through observability fields

If you have observability installed on your hub cluster, then you can access the observability fields on the {acm-short} console to view your virtual machine metrics. 

Access the observability fields by completing the following steps: 

. On the {acm-short} console, go to the `Virtual Machine` page. 
.. *Optional:* On the {acm-short} console, go to the `Launch links` table cell. 
. On the `Grafana` dashboard, select the link to the observability fields. 
. Use the observability field to view your virtual machine metrics.
