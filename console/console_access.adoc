= Access your console

[role="_abstract"]
The {acm} web console is integrated with the {ocp} web console as a console plug-in. You can access {acm-short} within the {ocp-short} console by selecting *Fleet Management* from the perspective selector.

Select the *Administrator* perspective when you want to use {ocp-short} console features on the cluster where you installed {acm-short}. Select *Fleet Management* from the perspective selector when you want to use {acm-short} features to manage your fleet of clusters.

*Important:* For {ocp} versions earlier than version 4.20, select *All Clusters* from the cluster switcher. If the cluster switcher is not present, the required console plug-ins might not be enabled. Also select *`local-cluster`* from the cluster switcher to use {ocp-short} console features.
