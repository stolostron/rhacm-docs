= Troubleshoot {mce-short}

[role="_abstract"]
Before using the Troubleshooting guide, you can run the `oc adm must-gather` command to gather details, logs, and take steps in debugging issues. For more details, see _Run the must-gather command to troubleshoot_.

Additionally, check your role-based access. See _Control access to cluster resources with {mce} role-based access control_ for details.

To view the main documentation about managing your clusters, see _Manage the cluster lifecycle_.
