[#troubleshooting-mce]
= Troubleshooting

[role="_abstract"]
Before using the Troubleshooting guide, you can run the `oc adm must-gather` command to gather details, logs, and take steps in debugging issues. For more details, see xref:../mce_troubleshooting/must_gather_mce.adoc#running-the-must-gather-command-to-troubleshoot-mce[Running the must-gather command to troubleshoot].

Additionally, check your role-based access. See link:../clusters/mce_rbac/rbac_mce.adoc#mce-rbac[{mce-short} Role-based access control] for details.
