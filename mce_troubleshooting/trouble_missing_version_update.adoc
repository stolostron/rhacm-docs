= Troubleshooting an attempt to update managed cluster with missing {ocp-short} version

[role="_abstract"]
You do not see the {ocp-short} version that you want in the console when you attempt to update your managed cluster in the console.

.Procedure

* Symptom: Attempt to update managed cluster with missing {ocp-short} version

+
When you attempt to update a managed cluster from the console and click *Update available* in the _Cluster details_ view to choose the {ocp-short} version from the dropdown list, the version is missing.
