[#must-gather-rhem]
= Must-gather procedure for the {rhem} agent

To debug the {rhem} agent on your devices, you can use the `flightctl-must-gather` command.

*Required access:* Cluster administrator

See the following procedure:

. Run the following command on the device that you want to debug:

[source,bash]
----
sudo flightctl-must-gather
----
