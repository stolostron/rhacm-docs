= Troubleshooting Klusterlet with degraded conditions

[role="_abstract"]
Klusterlet degraded conditions help you diagnose the status of the klusterlet agent on a managed cluster. When a Klusterlet is in a degraded condition, the agent might have errors that you need to troubleshoot. See the following information for Klusterlet degraded conditions that are set to `True`.

* *Symptom: Klusterlet is in the degraded condition*

+
After you deploy a Klusterlet on a managed cluster, the `KlusterletRegistrationDegraded` or `KlusterletWorkDegraded` condition displays a status of _True_.

* *Identifying the problem: Klusterlet is in the degraded condition*

+
. Run the following command on the managed cluster to view the Klusterlet status:

+
[source,bash]
----
kubectl get klusterlets klusterlet -oyaml
----

. Check `KlusterletRegistrationDegraded` or `KlusterletWorkDegraded` to see if the condition is set to `True`. Proceed to _Resolving the problem_ for any degraded conditions that are listed.

* *Resolving the problem: Klusterlet is in the degraded condition*

+
See the following list of degraded statuses and how you can attempt to resolve those issues:

* If the `KlusterletRegistrationDegraded` condition with a status of _True_ and the condition reason is _BootStrapSecretMissing_, you need to create a bootstrap secret in the `open-cluster-management-agent` namespace.

* If the `KlusterletRegistrationDegraded` condition displays _True_ and the condition reason is _BootstrapSecretError_ or _BootstrapSecretUnauthorized_, then the current bootstrap secret is invalid. Delete the current bootstrap secret and recreate a valid bootstrap secret in the `open-cluster-management-agent` namespace.

* If the `KlusterletRegistrationDegraded` and `KlusterletWorkDegraded` conditions display _True_ and the condition reason is _HubKubeConfigSecretMissing_, delete the Klusterlet and recreate it.

* If the `KlusterletRegistrationDegraded` and `KlusterletWorkDegraded` conditions display _True_ and the condition reason is _ClusterNameMissing_, _KubeConfigMissing_, _HubConfigSecretError_, or _HubConfigSecretUnauthorized_, delete the hub cluster kubeconfig secret from the `open-cluster-management-agent` namespace. The klusterlet agent creates a new hub cluster kubeconfig secret.

* If the `KlusterletRegistrationDegraded` condition displays _True_ and the condition reason is _GetRegistrationDeploymentFailed_ or _UnavailableRegistrationPod_, check the condition message to get the problem details and attempt to resolve.

* If the `KlusterletWorkDegraded` condition displays _True_ and the condition reason is _GetWorkDeploymentFailed_ or _UnavailableWorkPod_, check the condition message to get the problem details and attempt to resolve.
