[#troubleshooting-gitops-instance]
= Troubleshooting {gitops} instance 

[#symptom-gitops-instance-fails]
== Symptom: The {gitops-short} instnace fails 

The {gitops-short} instance can fail. 

[#resolving-the-problem-gitops-instance-check-logs]
== Resolving the problem: Checking the logs 

To resolve this problem, check the logs of the {gitops-short} instance. To check the logs, go to your managed cluster and get the pod of the {gitops-short} instance by running the following command:

[source,bash]
----
oc get pods -n openshift-gitops
----
