[#troubleshooting-gitops-addon]
= Troubleshooting GitOps add-on

[#symptom-gitops-addon-fails]
== Symptom: GitOps add-on fails to populate either the {gitops} operator or instance 

The GitOps add-on fails to populate either the {gitops} operator or instance.

[#resolving-the-problem-gitops-addon-check-logs]
== Resolving the problem: Checking the logs 

To resolve this problem, check the logs of the GitOps add-on controller by going to your managed cluster and running the following command: 

[source,bash]
----
oc logs -n open-cluster-management-agent-addon -l app=gitops-addon 
----
