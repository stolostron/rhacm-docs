[#trouble-automation-template]
= Troubleshooting automation template issues

If you encounter issues when using the automation template, also known as the cluster curator, follow the procedure to troubleshoot the problem.

[#symptom-automation-template]
== Symptom: Troubleshooting automation template issues

When using automation templates, you are unable to deploy managed clusters. The process might become stuck on the posthooks and not create any logs.

[#resolving-automation-template]
== Resolving the problem: Troubleshooting automation template issues

Complete the following steps to troubleshoot automation template issues:

. Check the `ClusterCurator` resource status in the cluster namespace for any messages or errors.

. Check the pod log of the `Job` resource named `curator-job-*`, which is in the same cluster namespace as the previous step.

*Note:* The job is removed after one hour due to a one hour time to live (TTL) setting.
