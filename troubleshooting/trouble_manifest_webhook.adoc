= Troubleshooting ManifestWork webhook limits

When you enable fine-grained role-based access control for virtualzation, the `MultiClusterRoleAssignment` controller aggregates every `roleAssignment` from `MultiClusterRoleAssignment` resources into a single shared `ClusterPermission` resource for each managed cluster namespace.

If your `roleAssignments` lists exceed the `ManifestWork` webhook size limit of 512KB, any new assignments for the cluster are rejected.

== Symptoms: Troubleshooting ManifestWork webhook limits

View the following symptoms:

- When you apply a valid `MultiClusterRoleAssignment` resource, the cluster permissions are never created on the managed cluster.

- The following error message appears in the logs of the `ClusterPermission` resource: `denied the request: the size of manifests is X bytes which exceeds the 512000 limit.`

== Identifying the problem: Troubleshooting ManifestWork webhook limits

To identify if the `ManifestWork` webhook limit is the problem, check the `mra-managed-permissions` `ClusterPermission` resource. Complete the following steps:

. Check the active failure by comparing your configurations. If the numbers do not match, the controller is unable to apply your latest changes from the `mra-managed-permissions` `ClusterPermission` resource. Replace `<managed-cluster-namespace>` with the namespace of your managed cluster.

.. Run the following command to count the desired bindings:

+
[source,bash]
----
oc get clusterpermission mra-managed-permissions -n <managed-cluster-namespace> -o yaml | grep "owner/" | wc -l
----

.. Run the following command to count the active bindings that are successfully applied:

+
[source,bash]
----
oc get clusterpermission mra-managed-permissions -n <managed-cluster-namespace> -o yaml | grep "reason: AppliedManifestComplete" | wc -l
----

. Check the current capacity of the `ClusterPermission` specification. When there are more than 360,000 bytes, you are at or exceeding the limit. Run the following command:

+
[source,bash]
----
oc get clusterpermission mra-managed-permissions -n <managed-cluster-namespace> -o jsonpath='{.spec}' | wc -c
----

== Resolving the problem: Troubleshooting ManifestWork webhook limits

To resolve the problem, remove assignments from some of the `MultiClusterRoleAssignment` objects. Complete the following steps:

. Identify specific `roleAssignments` in your `MultiClusterRoleAssignment` resources that you can manage separately.

. Remove the `roleAssignments` that you can manage separately from the `spec.roleAssignments` list in your `mra-managed-permissions` `ClusterPermission` resource.

. Re-create the `roleAssignment` permissions as individual `ClusterPermission` resources.
