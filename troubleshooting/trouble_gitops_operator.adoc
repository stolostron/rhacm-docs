[#troubleshooting-gitops-operator]
= Troubleshooting {gitops} operator

[#symptom-gitops-operator-fails]
== Symptom: The {gitops-short} operator fails 

The {gitops-short} operator can fail. 

[#resolving-the-problem-gitops-operator-check-logs]
== Resolving the problem: Checking the logs 

To resolve this problem, check the logs of the {gitops-short} operator manager. To check the logs, go to your managed cluster and get the pod of the {gitops-short} operator manager by running the following command:

[source,bash]
----
oc get pods -n openshift-gitops-operator
----
