[#troubleshooting]
= Troubleshoot {acm-short}

[role="_abstract"]
View troubleshooting topics for {acm-short} components. Before using the _Troubleshoot_ guides, you can run a `must-gather` command to gather details, logs, and take steps in debugging issues.

For more information about the `must-gather` command, see _Gathering data about your cluster_ in the {ocp-short} documentation.

Additionally, check your role-based access. See _Role-based access control_ for details.
