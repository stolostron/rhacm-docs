[#dr4hub-install-storage-secret]
= Create the storage location secret

[role="_abstract"]
Create a storage location secret for the cloud storage where backups are saved.

.Procedure

. Complete the steps for link:https://docs.redhat.com/en/documentation/openshift_container_platform/4.20/html/backup_and_restore/oadp-application-backup-and-restore[Creating a default Secret] for the cloud storage where the backups are saved.
. Create the secret resource in the OADP Operator namespace, which is located in the backup component namespace.
