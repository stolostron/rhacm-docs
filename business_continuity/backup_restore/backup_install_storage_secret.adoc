= Creating the storage location secret 

[role="_abstract"]
Create a storage location secret for the cloud storage where backups are saved.

.Procedure

. Complete the steps for _Creating a default Secret_ for the cloud storage where the backups are saved. 
. Create the secret resource in the OADP Operator namespace, which is located in the backup component namespace.
