= Backup and restore for hosted control planes and hosted clusters

The {ocp-short} {hcp} disaster recovery documentation describes how to use the {oadp} to backup and restore hosted clusters and how to install the {oadp} operator and create {oadp} resources. 

If you are using {acm-short}, you do not need to install the {oadp} operator in the default `openshift-adp` namespace. You can enable the backup and restore and use the {oadp} operator that is installed by the backup and restore component. 

{oadp} resources, such as `DataProtectionApplication`, `BackupSchedule`, `Backup` and `Restore` for your hosted clusters, are created in the `open-cluster-management-backup` namespace.

To restore the {acm-short} hub cluster, restore the hosted clusters by following link:https://docs.redhat.com/en/documentation/openshift_container_platform/4.17/html/hosted_control_planes/high-availability-for-hosted-control-planes#hcp-disaster-recovery-oadp[[OpenShift Hosted Control Plane Disaster Recovery documentation] before restoring the hub cluster.


See link:https://docs.redhat.com/en/documentation/openshift_container_platform/4.18/html/hosted_control_planes/[Overview of Hosted Cluster backup and restore process] and high-availability-for-hosted-control-planes#%20hcp-backup-restore-aws-overview_hcp-disaster-recovery-aws and [OpenShift Hosted Control Plane Disaster Recovery documentation](https://docs.redhat.com/en/documentation/openshift_container_platform/4.18/html/hosted_control_planes/high-availability-for-hosted-control-planes#hcp-disaster-recovery-oadp) on how to backup and restore hosted clusters.
