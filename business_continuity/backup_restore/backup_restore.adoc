[#restore-backup]
= Restore a backup

[role="_abstract"]
In a typical restore situation, the hub cluster where the backups run becomes unavailable, and you need to move the backed up data to a new hub cluster. Run the cluster restore operation on the new hub cluster. In this case, the restore operation runs on a different hub cluster than where the backup is created.

If you want to restore the data on the same hub cluster where the backup was collected, recover the data from an earlier snapshot. In this case, both restore and backup operations run on the same hub cluster.

To fully restore a backup, complete the following: 

.Procedure

. Use the restore operation for backup types. See xref:../backup_restore/backup_restore_types.adoc#restore-backup-types[Restore operation for backup types].
. Prepare the new hub cluster. See xref:../backup_restore/backup_restore_prepare.adoc#prepare-new-hub[Prepare the new hub cluster].
. Run a restore operation on a hub cluster with a newer version. See xref:../backup_restore/backup_restore_newer_version.adoc#run-restore-operation[Run a restore operation on a hub cluster with a newer version].
. Post restore clean up. See xref:../backup_restore/backup_restore_cleanup.adoc#clean-hub-restore[Post restore clean up].
. Restore passive resources. See xref:../backup_restore/backup_restore_passive.adoc#restore-passive-resources-check-backups[Restore passive resources while checking for backups].
. Restore activation resources. See xref:../backup_restore/backup_restore_activation.adoc#restore-activation-resources[Restore activation resources].
. Restore imported managed clusters. See xref:../backup_restore/backup_restore_imported.adoc#restore-imported-managed-clusters[Restore imported managed clusters].
. Use other restore samples. See xref:../backup_restore/backup_restore_samples.adoc#more-restore-samples[Restore samples].
. View restore events. See xref:../backup_restore/backup_restore_events.adoc#viewing-restore-events[View restore events].
