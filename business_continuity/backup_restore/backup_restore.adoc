[#restore-backup]
= Restore a backup

[role="_abstract"]
In a typical restore situation, the hub cluster where the backups run becomes unavailable, and you need to move the backed up data to a new hub cluster. Run the cluster restore operation on the new hub cluster. In this case, the restore operation runs on a different hub cluster than where the backup is created.

If you want to restore the data on the same hub cluster where the backup was collected, recover the data from an earlier snapshot. In this case, both restore and backup operations run on the same hub cluster.

To fully restore a backup, complete the following: 

.Procedure

. Use the restore operation for backup types. See _Restore operation for backup types_.
. Prepare the new hub cluster. See _Prepare the new hub cluster_.
. Run a restore operation on a hub cluster with a newer version. See _Run a restore operation on a hub cluster with a newer version_.
. Clean the hub cluster after restore. See _Clean the hub cluster after restore_.
. Restore passive resources. See _Restore passive resources while checking for backups_.
. Restore activation resources. See _Restore activation resources_.
. Restore imported managed clusters. See _Restore imported managed clusters_.
. Use other restore samples. See _Restore samples_.
. View restore events. See _View restore events_.
