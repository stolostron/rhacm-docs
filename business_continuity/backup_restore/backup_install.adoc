= Install the backup and restore operator

[role="_abstract"]
Install and enable the backup and restore operator on hub clusters by setting up your hub cluster. The cluster backup and restore operator is not installed automatically. 

.Prerequisites

* From your {ocp} cluster, install the {acm-short} operator version {product-version}. The `MultiClusterHub` resource is automatically created when you install {acm-short}, and displays the following status: `Running`.

Complete the following steps to set up your hub cluster for the installation.

.Procedure

. Enable the backup operator for your hub clusters. See 
_Enable the backup operator for your hub clusters_.
. Create a storage location secret. See _Create the storage location secret_.
. Install the OADP operator. See _OADP operator installation on the hub cluster_.
. Optional: Install a custom OADP version. See _Install a custom OADP version_.
. Create a `DataProtectionApplication` resource. See _Create a DataProtectionApplication resource_.
. If you are in a disconnected environment, enable the backup and restore component. See _Enable the backup and restore component in a disconnected environment_.
