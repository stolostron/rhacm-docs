[#dr4hub-install-backup-and-restore]
= Install the backup and restore operator

[role="_abstract"]
Install and enable the backup and restore operator on hub clusters by setting up your hub cluster. The cluster backup and restore operator is not installed automatically. 

.Prerequisites

* From your {ocp} cluster, install the {acm-short} operator version {product-version}. The `MultiClusterHub` resource is automatically created when you install {acm-short}, and displays the following status: `Running`.

Complete the following steps to set up your hub cluster for the installation.

.Procedure

. By default, the backup and restore operator is disabled. To enable the operator, see xref:../backup_restore/backup_install_enable_backup_operator.adoc[Enable the backup operator for your hub clusters].
. You must create a `Secret` resource that has credentials for your target backup location. See xref:../backup_restore/backup_install_storage_secret.adoc[Create the storage location secret].
. To help with disaster recovery, you need to install the OADP operator. See xref:../backup_restore/backup_install_oadp.adoc[OADP operator installation on the hub cluster].
. You can install a specific OADP version. See xref:../backup_restore/backup_install_oadp_custom.adoc[Install a custom OADP version].
. To define your backup locations and enable specific storage plugins, see xref:../backup_restore/backup_install_dpa.adoc[Create a `DataProtectionApplication` resource].
. If you are in a disconnected environment, you can enable the backup and restore operator. See xref:../backup_restore/backup_install_disconnected.adoc[Enable the backup and restore component in a disconnected environment].
