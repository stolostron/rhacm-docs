[#dr4hub-install-backup-and-restore]
= Installing the backup and restore operator

[role="_abstract"]
The cluster backup and restore operator is not installed automatically. Install and enable the operator by setting up your hub clusters.

.Prerequisites

* From your {ocp} cluster, install the {acm-short} operator version {product-version}. The `MultiClusterHub` resource is automatically created when you install {acm-short}, and displays the following status: `Running`. 

.Procedure

. Enable the backup operator for your hub clusters. See xref:../backup_restore/backup_install_enable_backup_operator.adoc#enabling-backup-operator-clusters[Enabling the backup operator for your hub clusters].
. Create a storage location secret. See xref:../backup_restore/backup_install_storage_secret.adoc#creating-the-storage-location-secret[Creating the storage location secret].
. Install the OADP operator. See xref:../backup_restore/backup_install_oadp.adoc#installing-the-oadp-operator[Installing the OADP operator].
. Optional: Install a custom OADP version. See xref:../backup_restore/backup_install_oadp_custom.adoc#installing-custom-oadp[Installing a custom OADP version].
. Create a `DataProtectionApplication` resource. See xref:../backup_restore/backup_install_dpa.adoc#creating-a-dataprotectionapplication-resource[Creating a _DataProtectionApplication_ resource].
. If you are in a disconnected environment, enable the backup and restore component. See xref:../backup_restore/backup_install_disconnected.adoc#enabling-the-backup-and-restore-component-in-a-disconnected-environment[Enabling the backup and restore component in a disconnected environment].
