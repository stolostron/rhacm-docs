[#dr4hub-install-backup-and-restore]
= Install the backup and restore operator

[role="_abstract"]
Install and enable the backup and restore operator on hub clusters. The cluster backup and restore operator is not installed automatically. 

.Prerequisites

* From your {ocp} cluster, install the {acm-short} operator version {product-version}. The `MultiClusterHub` resource is automatically created when you install {acm-short}, and displays the following status: `Running`.

Complete the following steps in order.

.Procedure

. xref:../backup_restore/backup_install_enable_backup_operator.adoc[Enable the backup operator for your hub clusters].
. xref:../backup_restore/backup_install_storage_secret.adoc[Create the storage location secret].
. xref:../backup_restore/backup_install_oadp.adoc[Install the OADP operator].
. xref:../backup_restore/backup_install_oadp_custom.adoc[Install a custom OADP version].
. xref:../backup_restore/backup_install_dpa.adoc[Create a `DataProtectionApplication` resource].
. xref:../backup_restore/backup_install_disconnected.adoc[Enable the backup and restore component in a disconnected environment].
. xref:../backup_restore/backup_install_enable_operator.adoc[Enable the backup and restore operator].
