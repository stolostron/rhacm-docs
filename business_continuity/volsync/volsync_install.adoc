= VolSync installation on managed clusters

[role="_abstract"]
To replicate a persistent volume claim from one managed cluster to another, install VolSync on both the source and the destination managed clusters. When you install VolSync from {acm-short}, the operator is installed in the `volsync-system` namespace on the managed cluster. That installation supports managed clusters that are not {ocp-short}.

If you installed VolSync as an {olm} operator on an {ocp-short} managed cluster in an earlier {acm-short} version, the VolSync {olm} operator is removed and replaced with the VolSync deployment in the `volsync-system` namespace.

You can install VolSync by adding a label to each managed cluster, or by creating a `ManagedClusterAddOn` resource on the hub cluster.
