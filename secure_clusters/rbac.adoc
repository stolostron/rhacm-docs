[#rbac-rhacm]
= Role-based access control

[role="_abstract"]
{acm} supports role-based access control (RBAC). Your role determines the actions that you can perform. RBAC is based on the authorization mechanisms in Kubernetes, similar to {ocp}.

*Note:* Action buttons are disabled from the console if the user-role access is impermissible.
