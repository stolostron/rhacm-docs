= Assigning fine-grained role-based access control in the console

Assign fine-grained virtualization roles to users and groups directly from the console. This allows you to grant specific permissions to manage virtual machines at the cluster or namespace level.

*Note:* Slide the *YAML* option on to see the data that you enter populate in the YAML editor.

*Required access:* Cluster administrator

.Prerequisites

See the following requirements to begin using fine-grained role-based access control:

- You need to install the latest version of {ocp-virt} on your hub cluster. For more information, see link:https://docs.redhat.com/en/documentation/openshift_container_platform/4.20/html/virtualization/installing[Virtualization - Installing].
- To learn about {ocp-short} default and virtualization roles and permissions, see link:https://docs.redhat.com/en/documentation/openshift_container_platform/4.20/html/virtualization/about#authorization_virt-security-policies[Authorization] in the {ocp-short} documentation.
- For details on how to enable role-based access control, see xref:../secure_clusters/rbac_implement_rhacm.adoc#rhacm-rbac-implement[Implementing role-based access control].

.Procedure

Complete the following steps to assign a role to a user or group:

1. From the navigation menu, select *Fleet management*.
2. Navigate to the *Identities* page by selecting *User management* > *Identities*.
3. Select the name of the user or group for which you want to assign permissions.
4. Select the *Role assignments* tab.
5. Click *Create role assignment*.
6. In the *Scope* field, select the scope of your role assignment.
+
*Note:* If you select the *Cluster set* scope, you must also define the *Namespace* scope for the set of clusters to which the user or group has permissions.
7. In the *Role* field, select the role you want to assign to the user or group.
8. Click *Create* to save the role assignment.

The new role assignment appears in the *Role assignments* table. The permissions are applied to the selected user or group immediately.
