[#certificates]
= Certificates

[role="_abstract"]
All certificates that are required by services that run on {acm-short} are created when you install {acm-short}. View the following list of certificates, which are created and managed by the following components of {ocp}:

* OpenShift Service Serving Certificates
* {acm-short} webhook controllers
* Kubernetes Certificates API
* OpenShift default ingress

*Required access:* Cluster administrator

*Note:* Users are responsible for certificate rotations and updates.
