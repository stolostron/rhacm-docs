= Secure clusters and control access to cluster resources

[role="_abstract"]
Use the role-based access control and authentication to identify the user associated roles and cluster credentials. To create and manage your cluster credentials, access the credentials by going to the Kubernetes secrets where they are stored. You might need to manually create and manage the access control on your cluster. To do this, you  must configure _authentication_ service requirements for {acm} to onboard workloads to Identity and Access Management (IAM).

*Required access:* Cluster administrator
