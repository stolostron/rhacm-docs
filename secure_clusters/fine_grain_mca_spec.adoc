[#fine-grain-mca-spec]
= _MulticlusterRoleAssignment_ resource specification

[role="_abstract"]
The resource definition consists of two primary sections: the _Subject_ that receives the permission, and the _Role Assignments_, which are the permissions that are granted and where they apply.

`spec.subject`:: Defines the identity that is receiving the permissions. See the following table for information about the subject specification:

+
.Subject specification
|===
| Field | Description

| `kind`
| The type of identity is specified. Supported values are `User` or `Group`.

| `name`
| The name of the user or group is specified, for example, `jane.doe@example.com` or `dev-team`.
|===

`spec.roleAssignments`:: A list of rules that define the roles to be granted, and the target clusters. See the following table for information about the role assignment specification:

+
.Role assignment specification
|===
| Field | Description

| `clusterRole`
| The name of the `ClusterRole` to assign. *Note:* This role must exist on the managed cluster before the assignment.

| `clusterSelection`
| Specifies the target clusters for this assignment using standard placement references.

| `targetNamespaces`
| *Optional:* A list of namespaces on the managed cluster where the role applies. This field determines the scope of the resulting binding.
|===
