[#install-acm-mcp]
= Install the {mcp-short} (Technology Preview)

[role="_abstract"]
Install the {mcp-short} from the published Helm repository on your {acm-short} hub cluster. The Helm chart automatically discovers your {acm-short} `MultiClusterHub` installation, extracts database credentials, and deploys the {mcp-short} with the required configuration.

*Required access:* Cluster administrator

.Prerequisites

* An {ocp-short} cluster with {acm-short} installed. See link:../install/install_overview.adoc#installing-acm-overview[Installing and upgrading overview].
* Helm 3.x installed locally. For more information, see link:https://helm.sh/docs/intro/install/[Installing Helm].
* Access to the cluster using the `oc` command. See link:https://docs.redhat.com/en/documentation/openshift_container_platform/4.20/html/cli_tools/openshift-cli-oc#cli-getting-started[Getting started with the OpenShift CLI] in the {ocp-short} documentation.

.Procedure

. Add the {mcp-short} Helm repository. Run the following command:

+
[source,bash]
----
helm repo add acm-search https://raw.githubusercontent.com/stolostron/search-mcp-server/main/charts
helm repo update
----

. Install the {mcp-short} with auto-discovery. Run the following command:

+
[source,bash]
----
helm install acm-mcp-server acm-search/acm-mcp-server \
  --create-namespace \
  --namespace acm-search
----

+
The Helm chart automatically completes the following tasks:

* Discovers your {acm-short} `MultiClusterHub` installation
* Builds the complete database connection URL
* Deploys the {mcp-short} with the required configuration

. Verify that the {mcp-short} is running in the `acm-search` namespace. Run the following command:

+
[source,bash]
----
oc get pods -n acm-search
----

+
After you install the {mcp-short}, you can connect your AI assistants or MCP clients.
