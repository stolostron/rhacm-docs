= {mcp-short} overview (Technology Preview)

[role="_abstract"]
The {mcp-short} is a Model Context Protocol (MCP) server that provides access to the {acm} search database that stores information about Kubernetes resources across managed clusters.

*Note:* You must have {acm-short} installed.

Use the {mcp-short} to query cluster resources from artificial intelligence assistants and other MCP clients. The server shows tools that search the same data that powers the {acm-short} search service.

* *Available tools:* The {mcp-short} provides the `find_resources` tool for advanced Kubernetes resource search across all managed clusters.

+
* *Basic filters:* `kind`, `name`, `namespace`, `cluster`, `status`
* *Advanced filters:* `labelSelector`, `clusterSelector`, `textSearch`, `ageNewerThan`, `ageOlderThan`
* *Output control:* `outputMode` (`list`, `count`, `summary`, or `health`), `groupBy`, `sortBy`, `sortOrder`, `limit`, `countOnly`
+
*Note:* The {mcp-short} provides the output controls and filters that the {mcp-server} enables for your artificial intelligence agents to use.
