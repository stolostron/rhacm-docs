= {mcp-short} overview (Technology Preview)

[role="_abstract"]
The {mcp-short} is a Model Context Protocol (MCP) server that provides access to the {acm} search database, which stores information about Kubernetes resources across managed clusters.

You must have {acm-short} installed to use the {mcp-short}. See link:../install/install_overview.adoc#installing-acm-overview[Installing and upgrading overview].

Use the {mcp-short} to query cluster resources from AI assistants and other MCP clients. The server shows tools that search the same data that powers the {acm-short} search service.

The {mcp-short} provides output controls and filters for your artificial intelligence agents to use.

* *Available tools:* The {mcp-short} provides the `find_resources` tool for advanced Kubernetes resource search across all managed clusters.

+
* *Basic filters:* `kind`, `name`, `namespace`, `cluster`, `status`
* *Advanced filters:* `labelSelector`, `clusterSelector`, `textSearch`, `ageNewerThan`, `ageOlderThan`
* *Output control:* `outputMode` (`list`, `count`, `summary`, or `health`), `groupBy`, `sortBy`, `sortOrder`, `limit`, `countOnly`
