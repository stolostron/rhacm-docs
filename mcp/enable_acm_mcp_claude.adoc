= Enable the {mcp-short} with Claude Code (Technology Preview)

[role="_abstract"]
Configure and run Claude Code on your machine to connect to the {mcp-short} that is installed on your {acm-short} hub cluster. After you configure Claude Code, you can query {acm-short} search data.

.Prerequisites

* You must install {acm}. See link:../install/install_overview.adoc#installing-acm-overview[Installing and upgrading overview].
* The {mcp-short} is installed on your {acm-short} hub cluster. See xref:../mcp/install_acm_mcp.adoc#install-search-mcp[Installing the {mcp-short}].
* Claude Code is installed on the machine where you run this procedure.

.Procedure

. Log in to the {acm-short} hub cluster by using the `oc` command.

. Retrieve the route that was created by the {mcp-short} installation in the `acm-search` namespace:

+
[source,bash]
----
export ROUTE=$(oc get route acm-mcp-server -n acm-search -o jsonpath='{.spec.host}')
----

. Run the following command to add the {mcp-short} to Claude Code:

+
[source,bash]
----
claude mcp add --transport http -s project acm-search https://${ROUTE}/mcp --header "Authorization: Bearer $(oc whoami -t)"
----

. Log in to Claude Code, connect to the {mcp-short} named `acm-search`, use the tools.

. *Note:* If your cluster uses a self-signed certificate, start Claude by setting the `NODE_TLS_REJECT_UNAUTHORIZED` environment variable to `0` in your command-line environment:

+
[source,bash]
----
export NODE_TLS_REJECT_UNAUTHORIZED=0
----
